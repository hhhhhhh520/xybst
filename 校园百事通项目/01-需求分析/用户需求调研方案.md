# 校园百事通智能体 - 用户需求调研

## 一、调研目标

1. 了解师生在校园信息查询方面的痛点和需求
2. 收集高频问题类型，指导知识库建设
3. 确定功能优先级，指导产品开发
4. 验证产品价值，为后续推广做准备

## 二、调研方法

### 2.1 问卷调查（定量）
- **样本量**：200名学生 + 30名教师
- **发放渠道**：班级群、学生会、教师群
- **调研时间**：3-5天

### 2.2 深度访谈（定性）
- **访谈对象**：
  - 大一新生 3名（信息获取焦虑）
  - 大二/大三学生 3名（学业发展需求）
  - 大四学生 2名（毕业事务需求）
  - 辅导员/班主任 2名（学生工作视角）
  - 教务处/学工处老师 2名（行政服务视角）

## 四、访谈提纲

### 学生访谈提纲（30分钟）

**开场（5分钟）**
- 自我介绍，说明访谈目的
- 确认是否同意录音（仅用于整理）

**主体问题（20分钟）**

1. **日常信息查询场景**
   - 您平时最常查询哪些校园信息？
   - 最近一次查询是什么时候？查什么？怎么查的？
   - 整个查询过程花了多长时间？顺利吗？

2. **痛点深挖**
   - 有没有遇到过怎么都找不到答案的情况？
   - 有没有得到过错误信息，导致耽误事的经历？
   - 非工作时间（晚上/周末）有紧急问题怎么办？

3. **对AI助手的期待**
   - 如果有个AI助手能回答校园问题，您最希望它解决什么？
   - 您会担心什么问题？（准确性、隐私等）
   - 什么情况下您会选择问AI而不是问同学/老师？

4. **功能优先级**
   - 如果只能做3个功能，您选哪3个？
   - 您愿意为使用这个服务付出什么？（如：看广告、付费、分享等）

**结束（5分钟）**
- 还有什么想补充的？
- 是否愿意在产品测试阶段参与体验？
- 感谢并赠送小礼品

### 教师访谈提纲（30分钟）

**开场（5分钟）**
- 自我介绍，说明访谈目的

**主体问题（20分钟）**

1. **工作现状**
   - 您的工作中，有多少时间花在回答学生咨询上？
   - 最常回答的问题类型是什么？
   - 有没有FAQ或常见问题的整理？

2. **痛点与需求**
   - 重复性问题是否占用大量时间？
   - 有没有因为信息传达不到位导致的问题？
   - 希望如何提升学生服务效率？

3. **对AI助手的看法**
   - 您认为AI助手能替代哪些工作？
   - 您会担心什么问题？（如学生不再看通知）
   - 希望如何与AI助手协作？

**结束（5分钟）**
- 是否愿意提供部门的相关政策文档用于知识库建设？
- 感谢

## 五、数据分析计划

### 定量分析
- 各年级需求差异分析
- 功能需求优先级排序
- 痛点严重程度统计

### 定性分析
- 访谈记录编码分类
- 典型用户故事提取
- 需求场景归纳

### 输出成果
1. 用户需求调研报告
2. 用户画像（3-4个典型角色）
3. 功能优先级清单
4. 高频问题清单（用于知识库建设）

## 七、注意事项

1. **伦理合规**：问卷和访谈需说明数据仅用于项目研究，保护隐私
2. **样本代表性**：确保各年级、各学院样本均衡
3. **激励措施**：可设置抽奖或提供小礼品提高回收率
4. **文档保存**：所有原始数据保存，用于毕设附录
