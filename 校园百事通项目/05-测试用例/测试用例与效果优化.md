## 三、效果评估方案

### 3.1 评估指标体系

#### 准确性指标

| 指标 | 定义 | 计算方法 | 目标值 |
|------|------|----------|--------|
| 回答准确率 | 回答正确的比例 | 正确数/总回答数 | ≥85% |
| 知识库覆盖率 | 有答案的问题比例 | 有答案数/总问题数 | ≥80% |
| 事实准确性 | 事实性错误比例 | 无事实错误数/总回答数 | ≥95% |

#### 完整性指标

| 指标 | 定义 | 计算方法 | 目标值 |
|------|------|----------|--------|
| 信息完整率 | 回答信息完整的比例 | 完整回答数/总回答数 | ≥80% |
| 引用完整率 | 正确标注来源的比例 | 正确引用数/总回答数 | ≥90% |

#### 用户体验指标

| 指标 | 定义 | 计算方法 | 目标值 |
|------|------|----------|--------|
| 用户满意度 | 用户满意的比例 | 满意评价数/总评价数 | ≥80% |
| 问题解决率 | 问题被解决的比例 | 已解决数/总问题数 | ≥75% |
| 对话轮数 | 平均解决问题所需轮数 | 总轮数/已解决问题数 | ≤3轮 |

### 3.2 人工评估方案

#### 评估样本准备

- 准备100个标准测试问题，覆盖各业务场景
- 问题按难度分级：简单(40%)、中等(40%)、困难(20%)
- 每个问题准备标准答案（参考答案）

#### 评估维度与评分标准

| 维度 | 权重 | 评分标准（1-5分） |
|------|------|-------------------|
| 准确性 | 40% | 5=完全准确，4=基本准确，3=有小错，2=有较大错误，1=完全错误 |
| 完整性 | 25% | 5=信息完整，4=较完整，3=基本完整，2=有遗漏，1=严重缺失 |
| 易懂性 | 20% | 5=非常清晰，4=清晰，3=一般，2=较混乱，1=难以理解 |
| 友好度 | 15% | 5=非常友好，4=友好，3=一般，2=较生硬，1=不友好 |

#### 评估流程

1. 邀请评估人员（10位同学、5位老师）
2. 每位评估人员独立测试并评分
3. 汇总评分，计算平均分
4. 分析低分案例，找出改进点

### 3.3 自动评估方案

```python
# 自动评估脚本示例

def evaluate_answer(question, answer, reference):
    """
    自动评估回答质量

    Args:
        question: 用户问题
        answer: 智能体回答
        reference: 参考答案

    Returns:
        score: 综合得分
        details: 各维度得分
    """
    scores = {}

    # 1. 语义相似度（使用Embedding）
    answer_emb = get_embedding(answer)
    ref_emb = get_embedding(reference)
    semantic_sim = cosine_similarity(answer_emb, ref_emb)
    scores['semantic'] = semantic_sim

    # 2. 关键词覆盖率
    key_terms = extract_keywords(reference)
    coverage = sum(1 for term in key_terms if term in answer) / len(key_terms)
    scores['keyword_coverage'] = coverage

    # 3. 回答长度合理性
    ideal_length = len(reference)
    actual_length = len(answer)
    length_score = 1 - abs(actual_length - ideal_length) / ideal_length
    scores['length'] = max(0, length_score)

    # 4. 综合得分
    total_score = (
        scores['semantic'] * 0.4 +
        scores['keyword_coverage'] * 0.4 +
        scores['length'] * 0.2
    )

    return total_score, scores
```

#### 优化技巧一：查询重写

```python
# 查询重写示例

rewrite_templates = {
    "奖学金": ["奖学金申请", "奖学金评定", "奖学金条件", "奖学金时间"],
    "课表": ["课程表", "上课安排", "课程时间", "教室安排"],
    "证明": ["在读证明", "成绩单", "学籍证明", "证明办理"],
}

def rewrite_query(query):
    """扩展查询，提高召回率"""
    expanded = [query]

    for keyword, synonyms in rewrite_templates.items():
        if keyword in query:
            for syn in synonyms:
                expanded.append(query.replace(keyword, syn))

    return expanded
```

#### 优化技巧二：混合检索权重调优

```python
# RRF融合算法实现

def rrf_fusion(vector_results, keyword_results, k=60):
    """
    Reciprocal Rank Fusion

    Args:
        vector_results: 向量检索结果 [(doc_id, score), ...]
        keyword_results: 关键词检索结果 [(doc_id, score), ...]
        k: RRF参数

    Returns:
        fused_results: 融合后的结果
    """
    scores = {}

    # 向量检索得分
    for rank, (doc_id, _) in enumerate(vector_results):
        scores[doc_id] = scores.get(doc_id, 0) + 1 / (k + rank + 1)

    # 关键词检索得分
    for rank, (doc_id, _) in enumerate(keyword_results):
        scores[doc_id] = scores.get(doc_id, 0) + 1 / (k + rank + 1)

    # 排序
    fused_results = sorted(scores.items(), key=lambda x: x[1], reverse=True)
    return fused_results
```

#### 优化技巧三：上下文增强

```python
# 为chunk添加上下文信息

def enhance_chunk(chunk, doc_metadata, surrounding_chunks=None):
    """
    增强chunk内容

    Args:
        chunk: 原始chunk内容
        doc_metadata: 文档元数据
        surrounding_chunks: 相邻chunks（可选）

    Returns:
        enhanced_chunk: 增强后的chunk
    """
    # 添加文档标题
    header = f"【{doc_metadata['title']}】\n"

    # 添加章节信息
    if 'section' in doc_metadata:
        header += f"章节：{doc_metadata['section']}\n"

    # 添加上下文摘要（如果是中间chunk）
    context = ""
    if surrounding_chunks:
        context = "前文摘要：" + surrounding_chunks['prev'][-100:] + "\n"

    enhanced = header + context + "\n" + chunk

    return enhanced
```

## 五、异常情况处理

### 5.1 异常情况分类与处理

| 异常类型 | 触发条件 | 处理策略 | 用户感知 |
|----------|----------|----------|----------|
| 检索无结果 | 相似度<0.5 | 兜底答复+引导至人工 | "这个问题我暂时不太确定..." |
| 检索结果冲突 | 多个来源信息不一致 | 列出不同来源，让用户判断 | "根据A...根据B...建议您确认" |
| 生成超时 | >10秒未返回 | 返回预设回复，异步完成 | "正在为您查询，请稍候..." |
| 插件调用失败 | API异常 | 降级为知识库问答 | "系统暂时无法访问，您可以了解一般流程" |
| 敏感内容 | 命中敏感词 | 拒绝回答，记录日志 | "这个问题我暂时无法回答" |
| 用户输入异常 | 空输入/超长/乱码 | 友好提示重新输入 | "请输入您的问题" |

### 5.2 异常处理代码示例

```python
# 异常处理装饰器

def handle_exceptions(func):
    def wrapper(*args, **kwargs):
        try:
            return func(*args, **kwargs)
        except RetrievalError as e:
            logger.error(f"检索失败: {e}")
            return fallback_response("检索服务暂时不可用")
        except GenerationError as e:
            logger.error(f"生成失败: {e}")
            return fallback_response("正在为您查询，请稍候...")
        except PluginError as e:
            logger.error(f"插件调用失败: {e}")
            return fallback_response("相关系统暂时无法访问")
        except Exception as e:
            logger.error(f"未知错误: {e}")
            return fallback_response("系统繁忙，请稍后再试")
    return wrapper

# 兜底回复生成
def fallback_response(reason):
    """生成兜底回复"""
    templates = {
        "检索失败": "抱歉，我暂时没有找到相关信息。建议您拨打相关部门电话咨询。",
        "生成超时": "正在为您查询，请稍候...",
        "插件失败": "相关系统暂时无法访问，您可以先了解一般办理流程。",
        "系统繁忙": "系统繁忙，请稍后再试。",
    }
    return templates.get(reason, "抱歉，请稍后再试。")
```
