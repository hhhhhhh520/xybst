# 湖南农业大学学生违纪处分办法

> 依据湖南农业大学相关管理规定整理

## 第一章 总则

### 目的

为维护学校正常的教育教学秩序和生活秩序，建设良好的校风学风，保障学生合法权益，根据教育部《普通高等学校学生管理规定》及有关法律法规，结合学校实际，制定本办法。

### 适用范围

本办法适用于学校接受普通高等学历教育的研究生、本科、专科（高职）学生。

## 第二章 处分种类

### 处分等级

对学生违纪行为的处分分为以下五级：

| 处分等级 | 严重程度 |
|----------|----------|
| 警告 | 最轻 |
| 严重警告 | 较轻 |
| 记过 | 中等 |
| 留校察看 | 较重 |
| 开除学籍 | 最重 |

### 处分期限

- **警告、严重警告**：考察期一般为六个月
- **记过**：考察期一般为九个月
- **留校察看**：察看期一般为十二个月

## 第三章 违纪行为与处分

### 一、违反学习纪律

**旷课处分标准：**

| 旷课时数 | 处分等级 |
|----------|----------|
| 10-19学时 | 警告 |
| 20-29学时 | 严重警告 |
| 30-39学时 | 记过 |
| 40-49学时 | 留校察看 |
| 50学时以上 | 开除学籍 |

**其他违反学习纪律行为：**

1. 考试违纪或作弊，视情节轻重给予警告至开除学籍处分
2. 伪造、篡改成绩单、证明等材料的，给予记过以上处分
3. 学术不端行为，视情节轻重给予警告至开除学籍处分

### 二、违反生活秩序

**宿舍管理违纪：**

1. 擅自外出租房居住，经教育不改的，给予警告以上处分
2. 在宿舍内私拉乱接电线、使用违规电器，给予警告或严重警告处分；造成事故的，给予记过以上处分
3. 在宿舍内饲养宠物，经教育不改的，给予警告处分
4. 擅自调换、出租、出借宿舍床位，给予警告或严重警告处分

**其他生活违纪：**

1. 酗酒滋事，视情节轻重给予警告至留校察看处分
2. 赌博或为赌博提供条件的，给予严重警告以上处分
3. 恋爱行为不文明，造成不良影响的，给予警告以上处分

### 三、损害公共财物

1. 故意损坏公共设施、教学设备等，视情节轻重给予警告至留校察看处分，并赔偿损失
2. 污损、损坏图书馆书籍资料，给予警告以上处分，并赔偿损失
3. 破坏校园绿化、公共景观的，给予警告以上处分

### 四、违反治安管理规定

1. 打架斗殴，视情节轻重给予警告至开除学籍处分
2. 偷窃、诈骗公私财物，给予记过以上处分
3. 非法持有、传播违禁物品的，给予记过以上处分
4. 参与非法组织或活动的，给予记过以上处分

### 五、网络违纪

1. 利用网络散布虚假信息、造谣诽谤的，给予警告以上处分
2. 侵犯他人隐私、窃取他人账号的，给予严重警告以上处分
3. 传播不良信息的，给予警告以上处分
4. 攻击、破坏网络系统的，给予记过以上处分

## 第四章 处分程序

### 调查与认定

1. 违纪事件发生后，相关部门进行调查核实
2. 学生本人应当如实陈述事实，提供有关证据
3. 调查结束后，形成调查报告

### 处分决定

1. 学院提出处理建议，报学生工作处审核
2. 给予开除学籍处分的，提交校长办公会研究决定
3. 处分决定书送达学生本人

### 申诉权利

学生对处分决定有异议的，可以在收到处分决定书后10日内向学校学生申诉处理委员会提出书面申诉。

## 第五章 处分解除

### 解除条件

1. 处分期限已满
2. 深刻认识错误，并有悔改表现
3. 处分期无新的违纪行为
4. 其他应当解除处分的情形

### 解除程序

1. 学生提出解除处分申请
2. 班级、学院出具鉴定意见
3. 学生工作处审批
4. 解除处分决定送达学生本人

### 解除效力

解除处分后，学生获得表彰、奖励及其他权益，不再受原处分影响。
