# 湖南农业大学学生管理规定

> 依据《湖南农业大学学生管理规定》（2018年9月15日起施行）整理

## 第一章 总则

### 目的与依据

为规范学校学生管理，维护正常的教育教学秩序和生活秩序，保障学生合法权益，培养德、智、体、美等方面全面发展的社会主义建设者和接班人，依据教育法、高等教育法、教育部《普通高等学校学生管理规定》等有关法律、法规，制定本规定。

### 适用范围

本规定适用于学校对接受普通高等学历教育的研究生、本科、专科（高职）学生（以下称学生）的管理。

## 第二章 学生的权利与义务

### 学生享有的权利

1. 参加学校教育教学计划安排的各项活动，使用学校提供的教育教学资源
2. 参加社会实践、志愿服务、勤工助学、文娱体育及科技文化创新等活动
3. 申请奖学金、助学金及助学贷款
4. 在思想品德、学业成绩等方面获得科学、公正评价，完成规定学业后获得相应的学历证书、学位证书
5. 在校内组织、参加学生团体，以适当方式参与学校管理
6. 对学校给予的处理或者处分有异议，向学校、教育行政部门提出申诉
7. 法律、法规及学校章程规定的其他权利

### 学生应履行的义务

1. 遵守宪法和法律、法规
2. 遵守学校章程和规章制度
3. 恪守学术道德，完成规定学业
4. 按规定缴纳学费及有关费用
5. 遵守学生行为规范，尊敬师长，养成良好的思想品德和行为习惯
6. 法律、法规及学校章程规定的其他义务

## 第三章 学籍管理

### 入学与注册

1. **入学报到**：新生持录取通知书，按学校有关要求和规定的期限到校办理入学手续
2. **复查**：学校在三个月内按照国家招生规定进行复查，复查合格者予以注册，取得学籍
3. **注册**：每学期开学时，学生应当按学校规定办理注册手续

### 学业年限

1. **基本学制**：本科四年（部分专业五年），专科三年
2. **最长学习年限**：学生在校最长学习年限（含休学）为基本学制加两年

### 请假制度

**请假类型：**

| 请假类型 | 审批权限 | 说明 |
|----------|----------|------|
| 病假 | 校医院证明+辅导员审批 | 3天以上需学院审批 |
| 事假 | 辅导员审批 | 超过一周需学院审批 |
| 公假 | 相关部门证明+辅导员审批 | 参加学校活动、竞赛等 |

**请假流程：**

1. 学生填写请假申请表
2. 提供相关证明材料（病假需校医院证明）
3. 按请假天数报相应审批人审批
4. 请假获批后方可离校
5. 假期满后及时销假

**注意事项：**

- 请假累计超过一学期总学时三分之一者，应当休学
- 未经批准擅自离校者，按旷课处理
- 逾期不归且未续假者，按旷课处理

### 转专业与转学

**转专业条件：**

1. 学生一般应在被录取专业完成学业
2. 确有专长，转专业更能发挥其专长者
3. 入学后发现某种疾病或生理缺陷，经学校指定的医疗单位检查证明，不宜在原专业学习，但尚能在本校其他专业学习者
4. 学校认可的其他正当理由

**转专业程序：**

1. 学生提出申请，提交相关证明材料
2. 转出学院审核
3. 接收学院考核
4. 教务处审批
5. 公示无异议后办理手续

### 休学与复学

**休学条件：**

1. 因病经学校指定医院诊断，需停课治疗、休养占一学期总学时三分之一以上者
2. 根据考勤，一学期请假缺课超过该学期总学时三分之一者
3. 因创业等原因本人申请休学者
4. 学校认为应当休学者

**休学规定：**

- 休学一般以一年为期
- 休学次数一般不超过两次
- 休学期间不享受在校学习学生待遇
- 休学学生应当办理休学手续离校

**复学程序：**

1. 休学期满前向学校提出复学申请
2. 因病休学者需提交医院康复证明
3. 学校审查合格后，编入原专业相应年级学习

### 退学

**应予退学的情形：**

1. 学业成绩未达到学校要求或者在学校规定的学习年限内未完成学业的
2. 休学、保留学籍期满不办理复学手续的
3. 根据学校指定医院诊断，患有疾病或者意外伤残不能继续学习的
4. 未经批准连续两周未参加学校规定的教学活动的
5. 超过学校规定期限未注册而又未履行暂缓注册手续的
6. 学校规定的不能完成学业、应予退学的其他情形

### 毕业与结业

**毕业条件：**

1. 在规定学习年限内
2. 修完教育教学计划规定内容
3. 成绩合格
4. 达到学校毕业要求

**学位授予：**

符合学位授予条件者，授予相应学位。

**结业：**

在规定学习年限内，修完教育教学计划规定内容，但未达到毕业要求，准予结业，发给结业证书。
