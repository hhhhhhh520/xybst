# 湖南农业大学入党指南

## 一、申请入党基本条件

根据《中国共产党章程》第一条规定，申请入党必须具备以下条件：

1. 年满18周岁
2. 中国工人、农民、军人、知识分子和其他社会阶层的先进分子
3. 承认党的纲领和章程
4. 愿意参加党的组织并积极工作
5. 执行党的决议
6. 按期交纳党费

## 二、入党流程

### 流程图

```
提交入党申请书
       ↓
党支部谈话了解（约3个月考察）
       ↓
确定为入党积极分子
       ↓
培养教育考察（一年以上）
       ↓
确定为发展对象
       ↓
政治审查
       ↓
预审与公示（5个工作日）
       ↓
接收为预备党员
       ↓
预备期教育考察（一年）
       ↓
申请转正
       ↓
成为正式党员
```

### 各阶段说明

#### 第一阶段：申请入党

- 向所在单位党支部提交书面《入党申请书》
- 党支部将其列入《申请入党人名册》
- 支部指派专人进行第一次谈话，了解入党动机

#### 第二阶段：入党积极分子

- 经过约3个月考察后，支部委员会讨论确定
- 填写《入党积极分子考察表》
- 指定2名正式党员作为培养联系人
- 建立档案并报上级党组织备案
- 参加党校培训
- 每学期至少向支部汇报一次思想、工作和学习情况

#### 第三阶段：发展对象

- 经过**一年以上**培养教育
- 取得党校培训结业证书
- 支部听取党小组、培养联系人和党内外群众意见
- 团组织推荐（共青团员需经过团组织推优）
- 进行政治审查

#### 第四阶段：预备党员

- 填写《预审登记表》
- 经支部、党总支/分党委审核后报学校党委组织部预审
- 预审通过后公示5个工作日
- 支部大会讨论，采取无记名投票表决
- 上级党组织派人与发展对象谈话
- 审批通过后成为预备党员

#### 第五阶段：正式党员

- 预备期内参加组织生活、培训
- 每半年书面汇报思想
- 预备期满前7-15天提交转正申请
- 支部召开大会讨论转正
- 转正后入党材料归档，纳入个人档案

## 三、入党申请书

### 内容要求

1. 对党的认识
2. 入党动机
3. 个人成长经历
4. 家庭主要成员及社会关系情况
5. 自身优缺点分析
6. 今后的努力方向

### 格式要求

- 标题：入党申请书
- 称呼：敬爱的党组织
- 正文：上述内容
- 结尾：此致 敬礼
- 署名：申请人姓名
- 日期：年月日

## 四、培养考察要求

### 入党积极分子考察

| 考察内容 | 频率 |
|---------|------|
| 思想汇报 | 每学期至少1次 |
| 党校培训 | 必须参加并取得结业证书 |
| 支部谈话考察 | 每半年1次 |
| 培养联系人考察 | 持续进行 |

### 预备党员考察

| 考察内容 | 频率 |
|---------|------|
| 思想汇报 | 每半年至少1次书面汇报 |
| 组织生活 | 按时参加 |
| 党课学习 | 积极参加 |
| 实践锻炼 | 参与党组织安排的活动 |

## 五、"六个不发展"原则

有以下情况之一者，不予发展：

1. 未参加党校培训或未取得结业证书
2. 培养考察时间不足一年
3. 政治审查不合格
4. 群众意见较大
5. 入党动机不端正
6. 其他不符合党员条件的情况

## 六、入党时间参考

| 阶段 | 时间 |
|------|------|
| 提交申请书 | 大一入学后即可 |
| 确定为积极分子 | 大一下学期-大二上学期 |
| 确定为发展对象 | 大二下学期-大三上学期 |
| 接收为预备党员 | 大三下学期-大四上学期 |
| 转为正式党员 | 大四下学期-毕业后 |

**注意**：临近毕业或调离岗位（不足3个月）的发展对象一般不再发展

## 七、入党建议

### 尽早准备

- 大一入学后即可提交入党申请书
- 尽早参加党校培训
- 保持良好学业成绩
- 积极参与班级、学生组织工作

### 提升自我

1. **学业优秀**：成绩排名靠前更有优势
2. **学生工作**：担任学生干部可锻炼能力
3. **志愿服务**：积极参加志愿活动
4. **遵纪守法**：无违纪处分记录
5. **群众基础**：与同学关系融洽

### 注意事项

1. 入党动机要端正
2. 如实填写个人情况
3. 按时参加组织活动
4. 按时提交思想汇报
5. 保持与培养联系人沟通

## 八、常见问题

**Q：不入团可以直接入党吗？**
A：可以，但一般28周岁以下的青年入党需听取团组织意见，建议先入团。

**Q：入党需要多长时间？**
A：从提交申请书到成为正式党员，一般需要2-3年。

**Q：挂科影响入党吗？**
A：成绩是考察因素之一，挂科可能影响入党进程。

**Q：可以中途退出吗？**
A：可以，但已提交的材料会留存，建议慎重考虑后再申请。

**Q：入党对就业有帮助吗？**
A：部分岗位（如公务员、事业单位）对党员身份有要求，入党对求职有一定帮助。
