# 湖南农业大学创新创业扶持政策

## 一、创新创业学院

### 机构简介

湖南农业大学创新创业学院（创新创业指导服务中心）负责全校创新创业教育和服务工作。

### 服务内容

| 服务项目 | 说明 |
|---------|------|
| 创新创业导师库 | 提供导师资源支持 |
| 创业孵化基地 | 提供创业场地和孵化服务 |
| SIYB创业培训 | 系统的创业培训课程 |
| 项目申报指导 | 指导各类创业项目申报 |
| 竞赛组织 | 组织参加各类创新创业竞赛 |

### 联系方式

- 官网：https://cy.hunau.edu.cn/
- 地址：校内创新创业基地

## 二、大学生创新创业训练计划（大创）

### 项目类型

| 类型 | 说明 | 经费支持 |
|------|------|---------|
| 创新训练项目 | 学术研究、技术开发 | 校级5000元/项 |
| 创业训练项目 | 商业计划、创业准备 | 校级5000元/项 |
| 创业实践项目 | 真实创业实践 | 校级10000元/项 |

### 省级/国家级项目

| 类型 | 经费支持 |
|------|---------|
| 省级创新/创业训练项目 | 10000元/项 |
| 省级创业实践项目 | 50000元/项 |
| 国家级项目 | 按国家资助标准 |

### 申报时间

- 每年5月左右开始申报
- 具体时间以教务处和创新创业学院通知为准

### 申报流程

```
组建团队 → 确定选题 → 撰写申报书 → 导师指导 
→ 学院初审 → 学校审核 → 省级/国家级推荐
```

### 申报要求

1. 本科生团队（一般3-5人）
2. 指导教师1名
3. 项目具有创新性和可行性
4. 项目周期一般为1-2年

## 三、"互联网+"大学生创新创业大赛

### 大赛简介

中国国际"互联网+"大学生创新创业大赛是国内最具影响力的创新创业赛事，分为校级、省级、国家级三级。

### 参赛组别

| 组别 | 参赛对象 |
|------|---------|
| 高教主赛道 | 本科生、研究生 |
| 青年红色筑梦之旅 | 全体学生 |
| 职教赛道 | 职业院校学生 |

### 参赛项目类型

- 互联网+现代农业
- 互联网+制造业
- 互联网+信息技术服务
- 互联网+文化创意服务
- 互联网+社会服务

### 湖南农大历年成绩

- 第九届湖南省赛：4金9银5铜
- 多个项目入围全国总决赛

### 参赛流程

```
报名注册 → 提交项目 → 校赛选拔 → 省赛选拔 → 国赛
```

### 参赛时间

- 校赛：每年4-5月
- 省赛：每年6-8月
- 国赛：每年10月左右

## 五、创业孵化基地

### 基地功能

- 提供办公场地
- 提供创业指导
- 对接投资资源
- 协助办理工商注册
- 提供法律、财务咨询

### 入驻条件

1. 湖南农业大学在校生或毕业5年内校友
2. 有成熟的创业项目或商业计划
3. 项目具有创新性和市场前景
4. 团队结构合理

### 入驻流程

```
提交入驻申请 → 项目评审 → 签订入驻协议 → 入驻孵化
```

## 九、常见问题

**Q：大创项目必须和专业相关吗？**
A：不强制，但建议与专业相关或有导师指导的领域。

**Q：一个人可以参加多个项目吗？**
A：同一批次的同一个比赛一般只能参加一个项目。

**Q：创业项目一定要注册公司吗？**
A：创业实践项目建议注册公司，创业训练项目不强制。

**Q：创新创业成果可以抵学分吗？**
A：可以，创新创业成果可按学校规定认定学分。

**Q：大一新生可以参加大创吗？**
A：可以，但建议大一先了解，大二开始主持项目。
