# 湖南农业大学毕业生就业服务指南

> 依据湖南农业大学官网信息整理

## 就业服务概述

### 就业指导中心

**职责**：

- 就业政策咨询
- 就业信息发布
- 招聘会组织
- 就业手续办理
- 档案户口管理

**联系方式**：

- 关注学校就业信息网
- 各学院就业专干老师

### 就业信息服务

**信息发布渠道**：

| 渠道 | 说明 |
|------|------|
| 就业信息网 | 招聘信息、宣讲会通知 |
| 微信公众号 | 推送就业信息 |
| 班级群通知 | 学院就业专干发布 |
| 校园招聘会 | 现场招聘活动 |

## 就业手续办理

### 就业协议书（三方协议）

**签订流程**：

1. 毕业生与用人单位达成就业意向
2. 在就业信息网上填写就业意向
3. 打印三方协议（一式四份）
4. 用人单位盖章
5. 学校就业中心盖章
6. 协议生效

**注意事项**：

- 三方协议需在毕业前签订
- 签订后原则上不得违约
- 违约需办理解约手续

### 报到证办理

**办理时间**：毕业当年6-7月

**办理流程**：

1. 学校统一办理
2. 毕业生领取报到证
3. 按报到证指定地点报到

**报到期限**：

- 报到证有效期一般为2年
- 需在有效期内办理报到

### 档案转递

**档案去向**：

| 就业情况 | 档案去向 |
|----------|----------|
| 签就业协议 | 用人单位或当地人才市场 |
| 升学深造 | 录取学校 |
| 未就业 | 生源地人才市场或学校暂存 |
| 出国 | 生源地人才市场 |

**档案查询**：

- 毕业后可通过就业信息网查询档案去向
- 保留好档案转递通知单

### 户口迁移

**迁出办理**：

1. 凭报到证到保卫处办理
2. 领取户口迁移证
3. 在有效期内到目的地落户

**户口暂存**：

- 未就业毕业生可申请户口暂留学校
- 暂存期一般不超过2年

## 校园招聘

### 招聘会类型

| 类型 | 时间 | 说明 |
|------|------|------|
| 大型招聘会 | 春秋两季 | 数百家企业参会 |
| 专场招聘会 | 不定期 | 特定行业/企业 |
| 宣讲会 | 全年 | 企业宣讲+现场面试 |

### 参加招聘会准备

**材料准备**：

- [ ] 简历（多份）
- [ ] 成绩单
- [ ] 获奖证书复印件
- [ ] 就业推荐表
- [ ] 证件照

**着装准备**：

- 正装或商务休闲装
- 整洁大方

## 求职准备

### 简历制作

**简历结构**：

1. **基本信息**：姓名、联系方式、照片
2. **求职意向**：目标岗位、期望薪资
3. **教育背景**：学校、专业、学历、时间
4. **实习经历**：公司、岗位、主要工作、成果
5. **项目经验**：项目名称、角色、贡献
6. **技能证书**：语言能力、专业技能、证书
7. **获奖情况**：校级及以上荣誉
8. **自我评价**：突出个人优势

**注意事项**：

- 简历控制在一页A4纸
- 重点突出与应聘岗位相关的内容
- 数据化描述成果
- 无错别字、排版整洁

### 面试准备

**面试类型**：

| 类型 | 形式 | 准备要点 |
|------|------|----------|
| 结构化面试 | 标准问题 | 准备常见问题答案 |
| 无领导小组讨论 | 小组讨论 | 展现团队协作能力 |
| 专业面试 | 专业问题 | 复习专业知识 |
| HR面试 | 综合考察 | 了解企业文化、岗位要求 |

**常见面试问题**：

1. 请自我介绍
2. 为什么选择我们公司？
3. 你的优缺点是什么？
4. 对薪资的期望？
5. 未来职业规划？
6. 实习/项目中遇到的最大困难及解决方法？

## 升学深造

### 国内升学

**考研流程**：

1. 确定报考院校和专业
2. 复习备考
3. 网上报名（9-10月）
4. 现场确认（11月）
5. 初试（12月）
6. 复试（次年3-4月）
7. 录取通知（次年6-7月）

**保研途径**：

- 学习成绩优异，获得推免资格
- 参加夏令营获得优秀营员
- 参加高校预推免选拔

### 出国留学

**申请准备**：

1. 语言考试（雅思/托福）
2. 准备申请材料
3. 申请学校和专业
4. 获得录取通知
5. 办理签证

**材料清单**：

- 成绩单（中英文）
- 学位证明
- 语言成绩
- 推荐信
- 个人陈述
- 简历
- 资金证明

## 创业服务

### 创业支持政策

1. **创业培训**：免费创业培训课程
2. **创业孵化**：入驻学校创业孵化基地
3. **创业资金**：创业贷款、补贴申请
4. **创业指导**：创业导师一对一辅导

### 创业申请流程

1. 提交创业计划书
2. 学校创业学院评审
3. 入驻孵化基地
4. 享受相关支持政策

## 就业困难帮扶

### 帮扶对象

- 家庭经济困难毕业生
- 就业困难毕业生
- 残疾毕业生

### 帮扶措施

1. **就业指导**：一对一就业指导
2. **岗位推荐**：优先推荐就业岗位
3. **技能培训**：免费职业技能培训
4. **求职补贴**：申请求职创业补贴

## 常见问题

### Q1: 三方协议可以违约吗？

可以，但需承担违约责任：
1. 与用人单位协商解约
2. 取得解约证明
3. 申请新的三方协议
4. 部分单位需支付违约金

### Q2: 毕业后档案在哪里？

- 签就业协议的：档案转至用人单位或人才市场
- 升学的：档案转至录取学校
- 未就业的：档案转至生源地人才市场

### Q3: 报到证丢失怎么办？

- 在有效期内可申请补办
- 超过有效期可申请改派
- 联系学校就业中心办理

### Q4: 毕业后户口可以留校吗？

未就业毕业生可申请户口暂留学校，但一般不超过2年。建议及时迁出。
