# 湖南农业大学校医院与医保指南

## 一、校医院简介

湖南农业大学医院是由湖南农业大学主办的一级甲等公立医院，承担全校师生的预防保健、基本医疗服务、大学生健康教育、传染病预防和管理等职责。

### 基本信息

- **地址**：湖南农业大学校内
- **性质**：一级甲等公立医院
- **建筑面积**：4050平方米

## 五、大学生医保

### 参保方式

- 大学生纳入长沙市城乡居民基本医疗保险范围
- 由学校统一组织参保缴费
- 每年9月左右缴纳下一年医保费

### 医保费用

- 个人缴纳部分 + 政府补助部分
- 具体金额以当年政策为准

## 六、医保报销政策

### 校医院门诊报销

| 项目 | 政策 |
|------|------|
| 报销方式 | 即时报销 |
| 报销范围 | 医保目录内的诊疗项目和药品 |
| 报销比例 | 70% |
| 年度最高限额 | 800元 |
| 超出部分 | 全部自付 |

**注意**：普通门诊报销仅限校医院！

### 住院报销

| 项目 | 政策 |
|------|------|
| 住院起付线 | 500元 |
| 医保范围内报销比例 | 82% |
| 省内定点医院 | 直接在医院结算 |

### 不能报销的情况

1. 长沙市本地非定点医院住院
2. 门诊治疗（校医院除外）
3. 医保目录外的药品和诊疗项目
4. 整形美容等非医疗必需项目

## 七、校外就医报销

### 报销原则

- 住院才能报销（门诊不可报销）
- 省内定点医院住院直接在医院结算
- 省外或非定点医院需提交材料报销

### 报销材料

1. 医疗费用发票
2. 费用清单
3. 出院小结
4. 医院级别收费证明
5. 大学生假期疾病申报表（假期发病）
6. 意外伤害申请表（意外伤害）
7. 本人银行卡复印件

### 材料获取方式

| 材料 | 获取方式 |
|------|---------|
| 医院级别收费证明 | 医院提供或自己打印模板后医院盖章 |
| 大学生假期疾病申报表 | 学院勤工部、校勤工助学会贷款部 |
| 意外伤害申请表 | 学院勤工部、校勤工助学会贷款部 |

## 八、假期就医

### 假期疾病申报

- 假期间在户籍地或实习地生病住院的，需填写《大学生假期疾病申报表》
- 开学后及时提交报销材料

## 十二、常见问题

**Q：在校医院看病贵吗？**
A：校医院享受医保报销，门诊报销70%，费用较低。

**Q：周末可以去看病吗？**
A：可以，有值班医生，但建议常规疾病工作日就诊。

**Q：在校外医院看病能报销吗？**
A：住院可以报销（需按规定提交材料），门诊不能报销。

**Q：医保卡在哪里办理？**
A：大学生医保由学校统一办理，一般以社保卡或电子凭证形式使用。

**Q：看病需要带什么证件？**
A：带好校园卡或身份证，医保电子凭证。
