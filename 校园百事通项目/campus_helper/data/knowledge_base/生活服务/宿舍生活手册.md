# 湖南农业大学宿舍生活手册

## 一、宿舍园区分布

| 园区名称 | 位置 | 宿舍类型 | 设施情况 |
|---------|------|---------|---------|
| 芷兰园区 | 校园东侧 | 4-6人间 | 部分有独立卫浴、空调 |
| 丰泽园区 | 校园中部 | 4-6人间 | 有独立卫浴、空调 |
| 金岸园区 | 校园北侧 | 4-6人间 | 有独立卫浴、空调 |

## 二、宿舍设施

### 基本配置

- **床位**：上下铺或上床下桌
- **空调**：全部宿舍配备空调
- **独立卫浴**：大部分宿舍有独立卫浴
- **热水供应**：24小时热水（刷卡使用）
- **网络接口**：每床位有网络接口

### 公共设施

| 设施 | 位置 | 使用说明 |
|------|------|---------|
| 洗衣机 | 各楼栋洗衣房 | 微信/支付宝扫码付费 |
| 吹风机 | 楼层公共区域 | 扫码付费使用 |
| 饮水机 | 楼层公共区域 | 办理水卡或扫码 |
| 自习室 | 部分楼栋设有 | 安静学习场所 |

## 四、水电管理

### 电费缴纳

- **缴费方式**：关注"湖南农业大学"微信公众号 → 后勤服务 → 水电缴费
- **缴费地点**：学生事务大厅
- **免费额度**：每人每月有一定免费额度，超出需自费

### 水费

- 冷水：一般包含在住宿费中
- 热水：刷卡使用，按流量计费

## 五、电器使用规定

### 允许使用的电器

| 电器 | 功率限制 |
|------|---------|
| 手机充电器 | 不限 |
| 电脑 | 不限 |
| 台灯 | 不限 |
| 小风扇 | 不限 |
| 吹风机（小功率） | 500W以下 |

### 禁止使用的电器（违规电器）

| 电器类型 | 原因 |
|---------|------|
| 电饭煲、电磁炉 | 功率过大，安全隐患 |
| 热得快 | 极易引发火灾 |
| 电热毯 | 安全隐患 |
| 大功率吹风机 | 功率超过限制 |
| 电暖器 | 功率过大 |
| 微波炉 | 功率过大 |

**功率上限**：单个插座一般不超过1000W

### 违规电器处罚

- 首次发现：没收电器，批评教育
- 再次发现：通报批评，影响评优评先
- 造成事故：依规严肃处理

## 六、宿舍安全

### 消防安全

1. 不得在宿舍使用明火
2. 不得私拉乱接电线
3. 不得在宿舍吸烟
4. 消防通道保持畅通
5. 灭火器位置要清楚

### 防盗安全

1. 离开宿舍锁好门窗
2. 贵重物品妥善保管
3. 不要留宿外人
4. 发现可疑人员及时报告

## 七、宿舍报修

### 报修渠道

| 渠道 | 方式 |
|------|------|
| 线上报修 | "湖南农业大学"微信公众号 → 后勤服务 → 报修 |
| 电话报修 | 宿舍楼栋值班室电话 |
| 现场报修 | 宿管值班室登记 |

### 常见报修项目

- 空调故障
- 水管漏水
- 灯具损坏
- 门锁故障
- 网络故障

## 八、宿管值班

### 值班室位置

- 每栋宿舍楼一楼设有值班室
- 24小时有人值班

### 服务内容

- 出入管理
- 报修登记
- 物品借用（针线、打气筒等）
- 紧急情况处理

## 九、宿舍卫生

### 卫生要求

- 每天打扫宿舍卫生
- 物品摆放整齐
- 垃圾及时清理
- 被褥叠放整齐

### 检查制度

- 学院每周检查一次
- 学校不定期抽查
- 检查结果与评优挂钩

## 十、宿舍文明

### 禁止行为

1. 在宿舍吸烟、酗酒
2. 在宿舍饲养宠物
3. 在宿舍进行商业活动
4. 大声喧哗、影响他人休息
5. 在墙壁上乱涂乱画

### 保持安静时间

- 午休时间：12:30-14:00
- 晚间：22:00以后

## 十三、常见问题

**Q：可以自己选室友吗？**
A：新生宿舍一般由学校统一分配，大二开始可自行组合。

**Q：宿舍可以装饰吗？**
A：可以适当装饰，但不得破坏墙面，不得使用明火装饰。

**Q：可以在宿舍做饭吗？**
A：宿舍禁止使用大功率电器做饭，建议到食堂就餐。

**Q：宿舍有空调遥控器吗？**
A：有，入学时领取，遗失需自购。
