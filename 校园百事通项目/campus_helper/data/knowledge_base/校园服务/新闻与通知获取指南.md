# 湖南农业大学新闻与通知公告获取指南

## 一、学校新闻网

- **网址**：https://news.hunau.edu.cn/
- **主要内容**：
  - 学校新闻动态
  - 院系新闻
  - 学术活动
  - 校园文化
  - 媒体聚焦

### 新闻网栏目
| 栏目 | 内容 |
|-----|------|
| 综合新闻 | 学校重要新闻 |
| 院系动态 | 各学院新闻 |
| 学术科研 | 学术讲座、科研成果 |
| 校园文化 | 校园活动、学生风采 |
| 媒体聚焦 | 外媒报道 |

## 二、通知公告

- **网址**：https://www.hunau.edu.cn/tzgg/
- **主要内容**：
  - 学校各类通知
  - 公告公示
  - 招标采购
  - 人事任免
  - 其他重要通知

### 通知类型
- 教学通知：选课、考试、成绩等
- 学工通知：奖助学金、活动等
- 后勤通知：宿舍、餐饮、校园卡等
- 行政通知：假期安排、会议等

## 三、重要通知获取渠道

### 官方渠道
1. 学校官网通知公告栏目
2. 各部门网站通知
3. 学校官方微信公众号
4. 学院通知（班级群、学院网站）

### 关注建议
- 定期查看学校官网通知公告
- 关注学校官方微信公众号
- 加入班级群，及时获取学院通知
- 重要通知截图保存

## 四、常见重要通知类型

### 学期相关
- 开学时间
- 选课通知
- 考试安排
- 放假通知
- 补考通知

### 学籍相关
- 学籍异动通知
- 毕业相关通知
- 学位授予通知

### 奖助学金
- 奖学金评选通知
- 助学金申请通知
- 勤工助学岗位

### 就业相关
- 招聘会通知
- 就业政策
- 毕业生手续

### 其他
- 四六级报名
- 计算机等级考试
- 普通话测试
- 各类竞赛通知

## 五、通知查询技巧

1. **关键词搜索**：在通知公告页面使用关键词搜索
2. **分类浏览**：按通知类型分类查看
3. **时间筛选**：按发布时间筛选
4. **收藏保存**：重要通知收藏或截图

## 八、注意事项

2. 注意通知的发布时间和有效期
3. 重要通知及时保存或截图
4. 有疑问及时咨询相关部门
5. 警惕虚假通知，注意辨别
