# 湖南农业大学网上办事大厅使用指南

## 一、平台简介

- **网址**：https://ehall.hunau.edu.cn/
- **功能**：学校统一网上办事服务平台
- **登录方式**：统一身份认证（学号/工号 + 密码）

## 二、主要服务功能

### 1. 学籍证明类
- 在读证明
- 学籍证明
- 预计毕业证明
- 学生证补办申请

### 2. 成绩证明类
- 中文成绩单
- 英文成绩单
- 成绩排名证明
- GPA证明

### 3. 生活服务类
- 宿舍调换申请
- 校园卡服务
- 网络服务
- 报修服务

### 4. 教学服务类
- 选课服务
- 考试报名
- 教学评估
- 课程查询

### 5. 就业服务类
- 就业推荐表
- 三方协议
- 档案查询

## 三、使用流程

### 登录步骤
1. 访问 https://ehall.hunau.edu.cn/
2. 输入学号/工号和密码
3. 完成身份验证
4. 进入办事大厅首页

### 办事流程
1. 选择需要办理的事项
2. 阅读办事指南
3. 填写申请信息
4. 上传相关材料
5. 提交申请
6. 查看办理进度

## 四、常用功能详解

### 在读证明申请
1. 登录办事大厅
2. 搜索"在读证明"
3. 填写申请信息
4. 提交申请
5. 等待审核
6. 打印或领取证明

### 成绩单打印
1. 登录办事大厅
2. 搜索"成绩单"
3. 选择成绩单类型
4. 确认信息
5. 提交申请
6. 自助打印或到指定地点领取

### 宿舍调换申请
1. 登录办事大厅
2. 搜索"宿舍调换"
3. 填写申请理由
4. 提交申请
5. 等待审批结果

## 五、注意事项

1. 首次登录请修改初始密码
2. 妥善保管账号密码，不要借给他人
3. 提交申请前仔细核对信息
4. 关注申请进度，及时补充材料
5. 部分业务需到线下办理确认

## 六、常见问题

**Q: 忘记密码怎么办？**
A: 使用找回密码功能或联系信息化管理中心。

**Q: 申请提交后多久能办好？**
A: 不同事项办理时间不同，请查看办事指南或咨询相关部门。

**Q: 如何查看申请进度？**
A: 登录办事大厅，在"我的申请"中查看。

**Q: 申请被驳回怎么办？**
A: 查看驳回原因，补充材料后重新提交。

## 七、联系方式

- 技术支持：信息化管理中心
- 业务咨询：各相关部门
