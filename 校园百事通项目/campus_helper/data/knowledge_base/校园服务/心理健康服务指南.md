# 湖南农业大学心理健康服务指南

## 一、心理健康教育中心简介

湖南农业大学大学生心理健康教育中心是隶属于学生工作部的公益性心理咨询服务机构，为全校学生提供免费心理健康服务。

### 基本信息

- **机构性质**：公益性心理咨询服务机构
- **隶属部门**：学生工作部
- **服务对象**：全校学生
- **费用**：免费

## 二、服务内容

| 服务项目 | 说明 |
|---------|------|
| 个体心理咨询 | 一对一心理咨询 |
| 团体心理辅导 | 主题团体辅导活动 |
| 心理健康教育讲座 | 心理健康知识普及 |
| 心理测评 | 心理健康状况评估 |
| 危机干预 | 心理危机紧急援助 |
| 心理委员培训 | 班级心理委员培训 |

## 三、心理咨询预约

### 预约方式

| 方式 | 说明 |
|------|------|
| 现场预约 | 前往心理健康教育中心现场登记 |
| 电话预约 | 拨打中心电话预约 |
| 网上预约 | 通过学校系统预约（如有） |

### 咨询时间

- 工作日上班时间
- 具体时间以中心公告为准

### 咨询地点

- 校内心理健康教育中心
- 具体位置请关注学校通知

## 四、咨询流程

```
预约登记 → 确定咨询时间 → 接受咨询 → 后续跟进
```

### 注意事项

1. 建议提前至少一天预约
2. 首次咨询需填写基本信息表
3. 每次咨询约50分钟
4. 如需续约，在咨询结束时与咨询师约定

## 五、保密原则

### 保密承诺

心理咨询遵循严格的保密原则：

1. 咨询内容严格保密
2. 未经来访者同意，不向第三方透露
3. 咨询记录妥善保管

### 保密例外

以下情况可能需要突破保密原则：

1. 来访者有自伤或伤人风险
2. 涉及未成年人被虐待
3. 法律规定必须报告的情况

**注意**：即使突破保密，也会控制在最小范围

## 十、心理危机干预

### 危机信号

以下情况需要关注：

1. 情绪异常低落，持续两周以上
2. 出现自伤行为或言语
3. 突然交代"后事"
4. 行为异常突变
5. 严重失眠、食欲不振

### 应对措施

1. 保持陪伴，不离人
2. 倾听但不评判
3. 及时联系辅导员或心理中心
4. 必要时拨打急救电话

### 紧急联系

- 心理健康教育中心
- 辅导员
- 校医院急诊

## 十一、心理健康自助建议

### 日常维护

1. 规律作息，保证睡眠
2. 适度运动，释放压力
3. 培养兴趣，丰富生活
4. 保持社交，倾诉交流
5. 学会放松，调节情绪

### 自我调适方法

| 方法 | 说明 |
|------|------|
| 深呼吸放松 | 腹式呼吸，缓解紧张 |
| 正念冥想 | 关注当下，减轻焦虑 |
| 运动锻炼 | 有氧运动，释放压力 |
| 书写日记 | 记录情绪，梳理思绪 |
| 听音乐 | 放松心情 |

## 十二、常见问题

**Q：心理咨询是不是有病的人才去？**
A：不是，心理咨询是帮助解决心理困扰、促进个人成长的正常服务。

**Q：咨询会被别人知道吗？**
A：不会，心理咨询严格保密，不会影响学业和就业。

**Q：咨询需要花钱吗？**
A：校心理健康教育中心咨询服务对学生免费。

**Q：咨询需要多长时间？**
A：每次咨询约50分钟，咨询次数根据问题情况而定。

**Q：可以去校外咨询吗？**
A：可以，校外心理咨询机构也是选择，但需要自费。
