## 二、常见诈骗类型

### 针对大学生的常见诈骗

| 诈骗类型 | 手段 | 防范措施 |
|---------|------|---------|
| 冒充公检法 | 冒充警察、检察官，称涉嫌犯罪，要求转账 | 公检法不会电话要求转账，挂断电话，拨打110核实 |
| 冒充老师/辅导员 | 冒充老师借钱或要求转账 | 核实对方身份，当面确认 |
| 刷单诈骗 | 高额返利为诱饵，先给小利后骗大钱 | 天上不会掉馅饼，拒绝刷单 |
| 网购退款 | 称订单异常需要退款，诱导点击链接 | 通过官方渠道核实，不点陌生链接 |
| 助学金诈骗 | 冒充教育部门发放助学金，要求先交"手续费" | 助学金不需要先交费，通过学校核实 |
| 兼职诈骗 | 高薪兼职为诱饵，要求先交押金、培训费 | 正规兼职不收押金，警惕高薪诱惑 |
| 冒充客服 | 称账户异常需要验证，诱导提供验证码 | 官方客服不会索要验证码 |
| 网恋诈骗 | 建立恋爱关系后以各种理由借钱 | 网恋需谨慎，不轻易转账 |

### 防骗原则

1. **不轻信**：不轻信陌生来电、短信、网络信息
2. **不透露**：不透露个人身份证、银行卡、验证码等信息
3. **不转账**：不向陌生账户转账汇款
4. **要核实**：遇到可疑情况，通过官方渠道核实

## 三、校园诈骗应对

### 发现被骗后

1. 立即停止转账
2. 保存聊天记录、转账记录等证据
3. 拨打110报警
4. 联系银行尝试止付
5. 向辅导员报告

### 举报渠道

- 全国反诈中心电话：96110
- 校园报警电话：0731-84673666
- 辅导员、学院学工组

## 四、个人信息保护

### 需保护的信息

| 信息类型 | 风险 |
|---------|------|
| 身份证号 | 被冒用办理贷款、开户等 |
| 银行卡号 | 资金被盗 |
| 验证码 | 账户被盗 |
| 密码 | 账号被盗 |
| 学籍信息 | 被冒用身份 |
| 家庭信息 | 家人被诈骗 |

### 保护措施

1. 不在陌生网站填写个人信息
2. 不随意连接公共WiFi
3. 不在社交媒体过度暴露个人信息
4. 不同平台使用不同密码
5. 定期修改重要密码

## 五、宿舍消防安全

### 消防安全要求

1. 不在宿舍使用明火
2. 不使用违规电器（电饭煲、热得快等）
3. 不私拉乱接电线
4. 不在宿舍吸烟
5. 不堆放易燃物品
6. 保持消防通道畅通

### 消防设施

- 各楼栋配备灭火器
- 走廊设有消防栓
- 熟悉灭火器使用方法
- 记住消防通道位置

### 火灾应对

1. 发现火情立即拨打119
2. 小火可用灭火器扑灭
3. 大火立即疏散，不贪恋财物
4. 用湿毛巾捂住口鼻，低姿前行
5. 不乘坐电梯，走安全通道

## 六、地震等突发事件应对

### 地震避险

1. 室内：躲在桌子下或承重墙角，保护头部
2. 室外：远离建筑物，到空旷地带
3. 不乘坐电梯
4. 听从指挥有序疏散

### 疏散路线

- 熟悉宿舍、教室的疏散路线
- 参加学校组织的应急演练
- 知道最近的安全出口位置

## 七、人身安全

### 夜间出行

1. 尽量结伴而行
2. 选择灯光明亮的道路
3. 不要戴耳机隔绝环境
4. 遇到可疑人员及时躲避或报警

### 防范措施

1. 不独自去偏僻地方
2. 不轻易与陌生人搭话
3. 保持手机畅通，告知室友去向
4. 遇到危险大声呼救

## 八、财产安全

### 宿舍防盗

1. 离开宿舍锁好门窗
2. 贵重物品妥善保管
3. 不在宿舍存放大量现金
4. 不随意让陌生人进入宿舍

### 公共场所防盗

1. 手机、钱包不离开视线
2. 图书馆自习时贵重物品随身带
3. 运动时不让物品无人看管

## 九、校园欺凌与维权

### 什么是校园欺凌

- 言语侮辱、起绰号
- 故意孤立、排挤
- 肢体暴力
- 网络暴力
- 勒索财物

### 遭遇欺凌怎么办

1. 保护自己，避免冲突升级
2. 保留证据（截图、录音等）
3. 及时向辅导员、学院报告
4. 必要时报警

### 维权渠道

| 问题类型 | 维权部门 |
|---------|---------|
| 校园欺凌 | 辅导员、学院学工组、保卫处 |
| 个人信息泄露 | 保卫处、网信中心 |
| 消费纠纷 | 后勤中心、消费者协会 |
| 学业问题 | 教务处、学院 |
| 权益问题 | 学生处、学生会权益部 |

## 十一、常见问题

**Q：接到诈骗电话怎么办？**
A：不要慌张，挂断电话，不透露任何信息，可拨打110或96110核实举报。

**Q：被骗了钱能追回吗？**
A：发现被骗后立即报警，保存证据，越早报警追回的可能性越大。

**Q：宿舍发生火灾怎么办？**
A：小火用灭火器扑灭，大火立即疏散并拨打119，不要贪恋财物。

**Q：发现可疑人员怎么办？**
A：保持距离，记下特征，及时报告保卫处或拨打校园110。

**Q：校园安全投诉找谁？**
A：可联系保卫处、辅导员或通过校长信箱反映。
