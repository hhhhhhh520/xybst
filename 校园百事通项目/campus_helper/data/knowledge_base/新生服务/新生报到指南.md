# 湖南农业大学新生报到指南

## 一、报到时间

- **2025级本科新生报到时间**：2025年9月15日 7:00-24:00
- **建议提前1天到校**：9月14日可提前入住（需关注学校通知）

## 二、报到前准备

### 必备证件材料清单

| 材料名称 | 要求 | 备注 |
|---------|------|------|
| 录取通知书 | 原件 | 必须携带 |
| 身份证 | 原件+复印件3份 | 正反面复印在同一页 |
| 高考准考证 | 原件 | 部分省份需要 |
| 户口本复印件 | 户主页+本人页 | 办理相关手续用 |
| 团员档案 | 团员证+转团材料 | 共青团员需携带 |
| 党员档案 | 党组织关系介绍信 | 中共党员需携带 |
| 一寸照片 | 8张 | 白底或蓝底 |
| 二寸照片 | 4张 | 白底或蓝底 |
| 银行卡 | 农业银行卡 | 学费缴纳用 |
| 兵役登记证 | 男生需提供 | 年满18周岁男性 |

### 生活用品建议

- 床上用品（建议到校后购买，尺寸以宿舍实际情况为准）
- 换洗衣物（长沙夏季炎热，多带夏装）
- 常用药品（感冒药、肠胃药等）
- 学习用品
- 洗漱用品

## 四、报到地点

- **学校地址**：湖南省长沙市芙蓉区农大路1号
- **各学院报到点**：具体位置以迎新通知为准

### 交通路线

#### 从长沙火车站出发
- 公交：乘坐10路/110路公交车至"湖南农业大学"站
- 打车：约20分钟，费用约25元

#### 从长沙南站（高铁站）出发
- 地铁：乘坐地铁2号线 → 转乘公交或打车
- 打车：约30分钟，费用约40元

#### 从黄花机场出发
- 机场大巴：乘坐机场大巴至长沙火车站 → 转乘公交
- 打车：约40分钟，费用约60元

## 五、家长车辆入校

## 七、户口迁移（自愿）

### 办理流程

1. 凭录取通知书到户籍所在地派出所办理《户口迁移证》
2. 报到时将迁移证交至学校保卫处户政室
3. 学校统一办理落户手续

### 注意事项

- 户口迁移为自愿，学校不作统一要求
- 湖南省内迁移：只需提供户口本原件
- 湖南省外迁移：需办理《户口迁移证》
- 迁移地址：湖南省长沙市芙蓉区农大路1号湖南农业大学

### 是否建议迁户口？

| 情况 | 建议 |
|------|------|
| 农村户口（有土地分红） | 不建议迁移 |
| 毕业后打算留长沙发展 | 可迁移 |
| 毕业后回原籍发展 | 不建议迁移 |
| 方便办理证件 | 可迁移 |

## 八、缴费方式

### 学费缴纳

1. **银行卡代扣**：将学费存入农业银行卡，学校统一代扣
2. **网上缴费**：登录学校财务系统在线缴费
3. **现场缴费**：报到现场财务处窗口缴费

### 缴费时间

- 建议在报到前一周完成缴费
- 现场缴费需排队，耗时较长

## 九、绿色通道

家庭经济困难学生可申请"绿色通道"：
- 办理生源地信用助学贷款
- 申请缓交学费
- 报到时到绿色通道窗口办理
