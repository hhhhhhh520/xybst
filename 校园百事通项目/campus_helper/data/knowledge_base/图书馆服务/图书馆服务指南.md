# 湖南农业大学图书馆服务指南

## 一、图书馆基本信息

- **网址**：https://lib.hunau.edu.cn/
- **位置**：校园中心位置
- **开放时间**：
  - 周一至周日：8:00-22:00（具体以图书馆公告为准）
  - 考试期间可能延长开放时间
  - 法定节假日开放时间另行通知

## 二、馆藏资源

### 纸质资源
- 图书：涵盖农、工、理、经、管、文、法、教育等多学科
- 期刊：中外文期刊数千种
- 学位论文：本校博硕士学位论文

### 电子资源
- 中国知网（CNKI）
- 万方数据
- 维普期刊
- Web of Science
- Elsevier ScienceDirect
- Springer Link
- 其他专业数据库

## 三、借阅服务

### 借阅权限
| 读者类型 | 借阅册数 | 借阅期限 |
|---------|---------|---------|
| 本科生 | 10册 | 30天 |
| 研究生 | 15册 | 60天 |
| 教职工 | 20册 | 90天 |

### 借阅规则
1. 凭校园卡借阅图书
2. 图书到期前可续借一次
3. 逾期需缴纳滞纳金
4. 遗失图书需赔偿

### 借阅流程
1. 检索图书：通过图书馆官网或馆内检索机
2. 找书：根据索书号到相应书架
3. 借书：到借阅处办理借阅手续
4. 还书：到还书处或自助还书机

## 四、阅览服务

### 阅览室设置
- 社会科学阅览室
- 自然科学阅览室
- 期刊阅览室
- 电子阅览室
- 自习室
- 研讨室

### 座位预约
- 通过图书馆微信公众号或官网预约
- 预约成功后需在规定时间内签到
- 临时离开需保留座位

## 五、电子资源使用

### 校内访问
- 直接访问图书馆官网
- 点击数据库链接即可使用

### 校外访问
- 方式一：VPN连接校园网后访问
- 方式二：通过统一身份认证登录
- 方式三：使用CARSI认证

### 常用数据库使用指南
1. 中国知网：检索中文学术文献
2. 万方数据：学位论文、期刊等
3. Web of Science：外文文献检索
4. 读秀：图书检索与文献传递

## 六、其他服务

### 文献传递
- 本馆未收藏的文献可申请文献传递
- 通过图书馆官网提交申请
- 一般3-5个工作日获取

### 科技查新
- 为科研项目提供查新报告
- 需提前预约并提交相关材料

### 信息素养教育
- 新生入馆教育
- 数据库使用培训
- 文献检索课程

### 学科服务
- 学科馆员为各学院提供专业服务
- 定题服务、代检代查等

## 七、图书馆微信公众号

- 关注图书馆微信公众号获取最新动态
- 功能：座位预约、图书查询、续借、活动报名等

## 八、注意事项

1. 保持安静，不影响他人学习
2. 爱护图书和公共设施
3. 禁止在馆内吸烟、进食
4. 保管好个人物品
5. 按时归还图书，避免产生滞纳金

## 九、常见问题

**Q: 忘记还书怎么办？**
A: 登录图书馆系统查看借阅记录，及时归还并缴纳滞纳金。

**Q: 图书遗失如何处理？**
A: 可购买同版图书赔偿，或按图书馆规定进行现金赔偿。

**Q: 如何预约研讨室？**
A: 通过图书馆官网或微信公众号预约，需提前1-3天。

**Q: 寒暑假可以借书吗？**
A: 寒暑假期间图书馆开放时间会有调整，具体请关注通知。
