## 核心规章制度

### 一、课程考核管理

**文件名称**：《湖南农业大学全日制本科课程考核管理办法》
**发布日期**：2025年12月31日
**原文链接**：https://jwc.hunau.edu.cn/gzzd/xxj/202601/t20260105_507391.html

#### 主要内容

1. **考核方式**
   - 考试课程：闭卷考试为主
   - 考查课程：可采取论文、报告、实践操作等形式
   - 网络课程：线上考核

2. **成绩评定**
   - 百分制：60分及格
   - 五级制：优秀、良好、中等、及格、不及格
   - 绩点计算：按学校学分制方案执行

3. **补考与重修**
   - 补考安排：每学期初进行
   - 重修条件：补考仍不及格者需重修
   - 成绩记载：重修成绩按实际分数记载，注明"重修"

4. **缓考申请**
   - 申请条件：因病或其他不可抗力无法参加考试
   - 申请流程：考前提交缓考申请表及相关证明
   - 审批单位：教务处

#### 相关附件

- 成绩登记表
- 缓考申请表
- 考试违纪处理流程

### 二、毕业论文（设计）管理

**文件名称**：《湖南农业大学全日制普通本科生毕业论文（设计）工作实施办法》
**发布日期**：2025年09月04日
**原文链接**：https://jwc.hunau.edu.cn/gzzd/xxj/202509/t20250904_470726.html

#### 主要内容

1. **选题要求**
   - 应符合专业培养目标
   - 鼓励结合生产实际和科研课题
   - 一人一题，不得重复

2. **工作时间安排**
   - 第七学期：选题、开题
   - 第八学期：撰写、答辩
   - 具体时间以学院通知为准

3. **论文格式要求**
   - 使用学校统一模板
   - 字数要求：理工类不少于1万字，文科类不少于1.5万字
   - 查重率要求：一般不超过30%

4. **答辩与评分**
   - 答辩委员会组成
   - 成绩评定标准
   - 优秀论文评选

#### 相关附件

- 毕业论文（设计）模板
- 任务书
- 开题报告
- 中期检查表

### 三、创新创业成果替代毕业论文

**文件名称**：《湖南农业大学全日制本科生创新创业实践成果替代毕业论文（设计）管理办法》
**发布日期**：2025年08月25日
**原文链接**：https://jwc.hunau.edu.cn/gzzd/xxj/202508/t20250825_469923.html

#### 替代条件

符合以下条件之一的全日制本科生，可申请以创新创业实践成果替代毕业论文（设计）：

1. **学科竞赛获奖**
   - 国家级A类竞赛一等奖及以上
   - 省级A类竞赛特等奖、一等奖

2. **专利成果**
   - 发明专利授权（第一发明人或导师第一、学生第二）
   - 实用新型专利授权（第一发明人）

3. **学术论文**
   - 以第一作者发表SCI、SSCI、EI收录论文
   - 以第一作者发表北大核心期刊论文

4. **创业项目**
   - 创业项目获省级以上奖励
   - 创业企业运营良好并有实际成果

#### 申请流程

1. **提交申请**：填写《创新创业实践成果替代毕业论文（设计）申请表》
2. **学院审核**：学院教学指导委员会审核
3. **成果认定**：教务处组织专家认定
4. **成绩评定**：填写《成绩评定表》确定替代成绩

#### 需提交材料

- 《创新创业实践成果替代毕业论文（设计）申请表》
- 获奖证书、专利证书、论文原件及复印件
- 《创新创业实践成果创作过程说明报告》
- 其他支撑材料

### 四、课堂教学管理

**文件名称**：《湖南农业大学课堂教学管理规定》（湘农大〔2019〕21号）
**发布日期**：2019年07月08日
**原文链接**：https://jwc.hunau.edu.cn/gzzd/xxj/201907/t20190708_27195.html

#### 主要规定

1. **考勤要求**
   - 学生应按时上课，不得迟到、早退
   - 缺课累计超过课程学时1/3者，取消考试资格

2. **课堂纪律**
   - 遵守课堂秩序，尊重教师
   - 禁止使用手机做与教学无关的活动

3. **请假制度**
   - 病假需医院证明
   - 事假需提前申请
   - 请假累计超过课程学时1/4者需重修

### 七、学生违纪处分

**文件名称**：《湖南农业大学学生违纪处分办法》（湘农大〔2018〕31号）
**发布日期**：2018年09月11日
**原文链接**：https://jwc.hunau.edu.cn/gzzd/xxj/201809/t20180911_27174.html

> 📖 **详细版文档**：[《学生违纪处分办法》](../校规制度/学生违纪处分办法.md)（含处分标准表、违纪行为认定）

#### 处分等级

| 等级 | 适用情况 |
|------|----------|
| 警告 | 轻微违纪，初次违反 |
| 严重警告 | 较严重违纪 |
| 记过 | 严重违纪行为 |
| 留校察看 | 重大违纪，有悔改表现 |
| 开除学籍 | 极严重违纪 |

#### 常见违纪行为

- 考试作弊
- 学术不端
- 打架斗殴
- 违反宿舍管理规定
- 网络违纪

### 八、解除学生处分

**文件名称**：《湖南农业大学解除学生处分规定》（湘农大〔2018〕28号）
**发布日期**：2018年09月10日

#### 解除条件

1. 受处分后表现良好，无新的违纪行为
2. 考察期满（警告、严重警告6个月；记过、留校察看12个月）
3. 积极参加集体活动，完成学业任务
4. 撰写思想汇报，深刻认识错误

#### 申请流程

1. 学生提交解除处分申请
2. 班主任/辅导员签署意见
3. 学院审核公示
4. 学校审批

### 九、推荐免试攻读硕士（保研）

**文件名称**：《湖南农业大学推荐优秀应届本科毕业生免试攻读硕士学位研究生实施办法》
**发布日期**：2018年05月29日
**原文链接**：https://jwc.hunau.edu.cn/gzzd/xxj/201805/t20180529_27177.html

#### 推免条件

1. 纳入国家普通本科招生计划录取的应届毕业生
2. 品行表现优良，无任何违法违纪处分记录
3. 学业成绩优良，必修课无补考或重修记录
4. 外语水平达标（CET-4或CET-6成绩要求）
5. 学术发展潜力，有科研成果或竞赛获奖优先

#### 推免程序

1. 学院公布推免名额和条件
2. 学生提交申请材料
3. 学院审核并公示候选人
4. 学校推免工作领导小组审定
5. 公示推免名单

### 十、学分制实施

**文件名称**：《湖南农业大学学分制实施方案》（湘农大〔2012〕62号）
**发布日期**：2012年
**原文链接**：https://jwc.hunau.edu.cn/gzzd/xxj/201601/t20160114_27153.html

#### 主要内容

1. **学分计算**
   - 理论课：16学时=1学分
   - 实验课：32学时=1学分
   - 实习、毕业论文：1周=1学分

2. **学分要求**
   - 理工科：160-170学分
   - 文科：150-160学分

3. **选课制度**
   - 必修课、选修课、限选课
   - 选课时间和流程
   - 退补选规定

### 十二、辅修专业与双学位

**文件名称**：《湖南农业大学辅修专业学士学位教育管理暂行办法》（湘农大〔2016〕12号）
**发布日期**：2016年02月21日

#### 申请条件

1. 主修专业必修课无不及格
2. 平均学分绩点2.5以上
3. 学有余力，能完成辅修学业

#### 修读要求

- 辅修专业学分：30-50学分
- 修读年限：2-3年
- 学位授予：达到要求可授予辅修学士学位

### 十三、学生转学

**文件名称**：《湖南农业大学学生转学实施细则》（湘农大〔2015〕43号）
**发布日期**：2015年10月09日
**原文链接**：https://jwc.hunau.edu.cn/gzzd/xxj/201601/t20160114_27169.html

#### 转学条件

**可转学情况**：
- 因患病或家庭特殊困难，无法继续在本校学习
- 研究生因导师工作调动

**不得转学情况**：
- 入学未满一学期
- 招生时所在批次不同
- 低学历层次转入高学历层次
- 招生时确定为定向、委托培养

---

### 十四、学士学位授予

**文件名称**：《湖南农业大学授予学士学位工作细则》（湘农大〔2012〕57号）
**发布日期**：2012年
**原文链接**：https://jwc.hunau.edu.cn/gzzd/xxj/201601/t20160114_27151.html

#### 授予条件

1. 拥护中国共产党的领导，拥护社会主义制度
2. 完成培养方案规定的各项要求，成绩合格
3. 取得毕业资格
4. 学位课程平均学分绩点达到要求（一般≥2.0）

#### 不授予学位情况

- 未取得毕业资格
- 学位课程平均绩点未达标
- 考试作弊受到记过及以上处分
- 学术不端行为
