# 湖南农业大学保研与升学指南

## 一、保研（推免）政策

### 保研资格

湖南农业大学具有推荐优秀应届本科毕业生免试攻读硕士学位研究生（简称"推免"）的资格。

### 推免计划

| 年度 | 推免计划人数 |
|------|-------------|
| 2025年 | 263名 |
| 2026年 | 343名 |

### 计划分配

| 类型 | 名额 | 说明 |
|------|------|------|
| 服务国家发展战略计划 | 15名 | 分配给重点学科专业 |
| 奖励名额 | 7名 | 奖励研究生录取率高的专业 |
| 常规分配 | 剩余名额 | 根据各学院毕业生人数分配 |

## 二、保研申请条件

### 基本条件

1. 本校优秀应届本科毕业生
2. 专业学习成绩优秀
3. 外语能力达标
4. 综合素质评价优秀

### 外语能力要求

| 学生类型 | 要求 |
|---------|------|
| 英语、日语专业 | 通过专业四级考试 |
| 其他专业 | 英语四级≥425分 或 雅思≥5.5分 或 六级≥425分 |

## 三、保研申请流程

### 时间节点（以2025届为例）

| 环节 | 时间 |
|------|------|
| 学院制定细则 | 9月初 |
| 学生申请 | 9月中旬 |
| 材料提交截止 | 9月19日14:00前 |
| 学校审核公示 | 9月下旬 |
| 国家系统填报 | 9月底-10月 |

### 申请流程

```
关注通知 → 学院报名 → 提交材料 → 学院审核选拔 
→ 学院报送学校 → 学校审核公示 → 获得推免资格 
→ 国家系统填报志愿 → 参加招生单位复试
```

### 所需材料

1. 推免生申请表
2. 成绩单（加盖教务处公章）
3. 外语成绩证明
4. 获奖证书复印件
5. 科研成果、论文等（如有）
6. 其他证明材料

## 五、特殊政策

### 辅导员专项

- 鼓励学生保留入学资格一年，担任本校本科生辅导员
- 名额：不超过10人

### 支教专项

- 鼓励学生保留入学资格一年，参加研究生支教计划
- 名额：不超过8人

## 六、外校推免

### 申请外校条件

1. 获得本校推免资格
2. 符合目标院校接收条件
3. 通过目标院校复试

### 申请流程

1. 获得本校推免资格
2. 关注目标院校接收推免生通知
3. 在目标院校系统报名
4. 参加目标院校复试
5. 在国家系统确认录取

### 推荐目标院校

- 同层次院校：其他省属重点高校
- 更高层次：985/211高校、中科院等
- 专业对口：农业类、生物类优势院校

## 七、考研

### 考研时间线

| 时间 | 事项 |
|------|------|
| 9月 | 考研大纲发布 |

| 12月底 | 初试 |

| 类型 | 科目 |
|------|------|
| 学术型硕士 | 政治、英语一、数学（部分专业）、专业课 |

### 考研备考建议

1. **提前规划**：大三开始准备
2. **选择院校**：根据自身实力选择合适目标
3. **坚持复习**：制定计划，坚持执行
4. **关注信息**：关注研招网和目标院校通知

## 九、常见问题

**Q：保研需要什么成绩排名？**
A：一般要求专业前10%-20%，具体以学院细则为准。

**Q：保研可以报外校吗？**
A：可以，获得推免资格后可申请外校。

**Q：挂科影响保研吗？**
A：挂科会影响成绩排名，进而影响保研资格。

**Q：保研和考研可以同时准备吗？**
A：可以，但保研结果出来较晚，建议有保研希望的同学也关注考研。

**Q：学生干部经历对保研有帮助吗？**
A：学生干部经历可计入综合测评，有一定帮助。
