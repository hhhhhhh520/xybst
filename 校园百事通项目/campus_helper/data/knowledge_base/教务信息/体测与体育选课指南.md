## 一、体测基本信息

### 体测对象

- **主要对象**：在籍大三、大四（2022级、2023级）全体本科生
- **特殊说明**：大一、大二学生体育课期间统一测试
- **缓测说明**：2022级毕业生因实习、备考等特殊情况无法正常参加测试时，可在系统提交缓测申请

### 体测时间

- **测试时间段**：2026年3月30日-5月31日
- **每学年测试一次**：根据教育部要求，国家学生体质健康测试为每学年测试一次

## 五、体测评分标准

### 总分构成

体测总分 = 各项目得分之和

### 等级标准

| 等级 | 总分 |
|------|------|
| 优秀 | ≥90分 |
| 良好 | 80-89分 |
| 及格 | 60-79分 |
| 不及格 | <60分 |

### 毕业要求

- 体测成绩达到**50分**方可毕业
- 体测成绩纳入奖学金评选参考

## 六、免测与缓测

### 免测申请条件

1. 患有严重疾病或身体残疾
2. 近期做过手术，不宜剧烈运动
3. 其他经医生认定不宜运动的情况

### 申请流程

1. 登录体测预约系统
2. 点击左侧"体测免测申请"
3. 提交相关信息及附件材料（电子档或照片）
4. 等待大学生体质健康中心线上审核

### 缓测申请

- 因故不能按时参加测试的，可申请缓测
- 2022级毕业生因实习、备考等特殊情况无法正常参加测试时，可在系统提交缓测申请

## 七、体测注意事项

### 测试前准备

1. 测试前认真学习《<国家学生体质健康标准>各项目测试方法》
2. 测试前15分钟到达测试地点，充分做好准备活动
3. 合理安排作息时间，测试前注意休息，**切忌通宵熬夜**
4. 饭后至少半个小时方可参加测试，**不得空腹参加测试**

### 测试当天要求

1. **必须穿着运动服装和运动鞋**参加测试
2. **必须持本人身份证**参加测试，未携带证件者不得参加测试
3. 不得无故迟到、早退或不参加测试
4. 未按时参加测试的学生不再另行安排测试，测试成绩以零分计

### 测试过程中

1. 如感到身体不适，应及时向测试教师或测试工作人员报告
2. 服从工作人员的指挥
3. 对弄虚作假、舞弊或者冒名顶替者，一经发现取消测试资格，并报学校教务处以**考试作弊**处理

## 九、体育选课

### 选课时间

- 每学期初进行体育选课
- 具体时间以教务处通知为准

### 选课类型

| 课程类型 | 说明 |
|---------|------|
| 基础体育课 | 大一必修，学习基础体育知识 |
| 专项体育课 | 大二起可选，如篮球、足球、羽毛球、瑜伽等 |

### 选课入口

- 登录校园信息门户 → 教务系统 → 选课

### 选课技巧

1. 提前了解各项目课程内容
2. 首选感兴趣的或擅长的项目
3. 注意课程时间和地点
4. 选课系统开放时尽早选课，热门项目名额有限

## 十一、常见问题

**Q：体测不及格怎么办？**
A：体测不及格可在规定时间内申请补测。

**Q：体测成绩影响毕业吗？**
A：体测成绩需达到50分以上方可毕业。

**Q：体育课可以免修吗？**
A：因身体原因无法参加体育课的，可申请免修或修读保健体育课，需提供医院证明。

**Q：体育课挂科影响奖学金吗？**
A：体育课成绩计入综合测评，影响奖学金评选。

**Q：大三大四还有体育课吗？**
A：大一大二有体育必修课，大三大四无体育课但需参加体测。

**Q：错过预约时间怎么办？**
A：未按时参加测试的学生不再另行安排测试，测试成绩以零分计，请务必按时参加。

**Q：体测作弊会有什么后果？**
A：弄虚作假、舞弊或冒名顶替者，一经发现取消测试资格，并报学校教务处以考试作弊处理。
