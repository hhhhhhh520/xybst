# 教务处服务指南

## 教务处基本信息

- **地址**：长沙市芙蓉区农大路1号求真楼
- **电话**：(0731)84618042
- **官网**：https://jwc.hunau.edu.cn/

## 学生常用服务入口

所有教务服务均通过信息门户（https://portal.hunau.edu.cn/）登录：

| 服务项目 | 说明 |
|---------|------|
| 学生网上选课 | 每学期选课期间开放 |
| 学生网上评教 | 学期末对课程进行评价 |
| 空教室查询 | 查询空闲教室用于自习 |
| 成绩查询 | 查询学期成绩 |
| 课表查询 | 查看个人课程表 |
| 网络课程 | 在线学习平台 |

## 教务通知公告

教务处定期发布以下通知：
- 转专业工作通知（每学期）
- 选课通知
- 考试安排通知
- 教材发放通知
- 成绩相关通知

## 转专业

- **申请时间**：每学期初（具体时间以教务处通知为准）
- **申请流程**：通过信息门户提交申请 → 学院审核 → 公示结果
- **注意事项**：需满足转专业条件，部分专业有特殊要求

## 选课指南

- **选课时间**：每学期第16周左右（具体以通知为准）
- **选课系统**：http://jwxt.hunau.edu.cn/
- **选课类型**：
  - 必修课：系统自动分配
  - 选修课：自行选择
- **退改选**：选课期间可进行退改选操作

## 成绩查询

- **查询入口**：信息门户 → 成绩查询
- **成绩构成**：平时成绩 + 期末成绩
- **绩点计算**：按学校规定计算GPA

## 考试相关

- **考试时间**：学期末（具体以考试安排为准）
- **补考**：下学期初进行补考报名
- **重修**：不及格课程可申请重修

## 常用下载

教务处提供各类表格下载：
- 学生下载专区
- 办事指南
- 相关证明模板
