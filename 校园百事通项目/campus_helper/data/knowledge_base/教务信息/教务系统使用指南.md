## 学生服务功能

通过校园信息门户，学生可以使用以下功能：

### 1. 学生网上选课

**选课时间**：

- 第一轮选课：每学期期末前2周
- 第二轮选课：下学期开学第1周
- 补退选：开学第2周

**选课流程**：

1. 登录校园信息门户
2. 进入"教务管理" → "学生服务" → "学生网上选课"
3. 查看课程列表，选择需要修读的课程
4. 确认选课，系统显示选课成功

**选课注意事项**：

- 选课前务必查看本专业培养方案，了解必修、选修课程要求
- 注意课程时间冲突，避免重复选课
- 部分课程有人数限制，先选先得
- 选课后请及时核对课表

### 2. 成绩查询

**查询路径**：校园信息门户 → 教务管理 → 学生服务 → 成绩查询

**查询内容**：

- 历年各科成绩
- 学分统计
- 绩点计算
- 成绩排名

### 3. 课表查询

**查询路径**：校园信息门户 → 教务管理 → 学生服务 → 课表查询

**功能说明**：

- 查看本学期课程安排
- 查看课程详细信息（上课时间、地点、教师等）
- 可导出或打印课表

### 4. 学生网上评教

**评教时间**：每学期期末考试前2周至考试结束

**评教流程**：

1. 登录校园信息门户
2. 进入"学生网上评教"
3. 对本学期所学课程进行评价
4. 提交评教结果

**注意事项**：

- 评教结果匿名，请客观评价
- 未完成评教将影响成绩查询

### 5. 空教室查询

**查询路径**：校园信息门户 → 教务管理 → 学生服务 → 空教室查询

**功能说明**：

- 查询指定时间段空闲教室
- 查看教室座位数、设备配置
- 便于自习、社团活动使用

### 6. 网络课程

**访问路径**：校园信息门户 → 教务管理 → 学生服务 → 网络课程

**功能说明**：

- 在线学习通识选修课
- 查看课程视频、完成作业
- 参与在线考试

### 成绩复查

**申请时间**：成绩公布后1周内

**办理流程**：

1. 学生填写成绩复查申请表
2. 提交至学院教务办公室
3. 教务处组织复查
4. 复查结果反馈

### 学籍证明办理

**办理方式**：

1. 登录校园信息门户自助打印
2. 到教务处学籍科办理（需携带学生证）

## 考试相关

### 考试安排查询

**查询路径**：校园信息门户 → 教务管理 → 考试安排

**考试时间**：

- 期末考试：每学期最后2周
- 补考：开学第2-3周
- 重修考试：随下学期期末考试进行

### 考试注意事项

1. 携带学生证和身份证参加考试
2. 提前15分钟进入考场
3. 遵守考试纪律，违纪将受处分
4. 缓考需提前申请并获批准

## 常见问题

### Q1: 忘记密码怎么办？

1. 在登录页面点击"忘记密码"
2. 通过绑定的手机号或邮箱找回
3. 或携带学生证到信息中心重置密码

### Q2: 选课系统进不去怎么办？

选课高峰期系统可能拥堵，建议：

1. 错峰选课（如早上或晚上）
2. 使用校园网访问
3. 清除浏览器缓存
4. 更换浏览器（推荐谷歌浏览器）

### Q3: 成绩显示"缓考"怎么办？

缓考成绩会在补考结束后统一录入，如有问题请联系学院教务办公室。

### Q4: 如何申请免修？

部分课程可申请免修，需满足以下条件：

1. 有相关课程合格成绩或证书
2. 提交免修申请及相关证明材料
3. 经学院和教务处审批通过
