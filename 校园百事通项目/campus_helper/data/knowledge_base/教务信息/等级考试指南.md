# 湖南农业大学等级考试指南

## 一、大学英语四六级考试

### 报名时间

| 学期 | 报名时间 | 考试时间 |
|------|---------|---------|
| 上半年 | 4月下旬 | 6月中旬 |
| 下半年 | 9月下旬 | 12月中旬 |

### 报名条件

#### 四级（CET4）报名条件

| 学生类型 | 报名条件 |
|---------|---------|
| 2022级全日制本科生（本部） | 大学英语1课程成绩 ≥ 75分 |
| 东方科技学院学生 | 大学英语A1/B1成绩 ≥ 80分 |
| 中外合作办学学生 | 雅思综合1成绩 ≥ 75分 |

#### 六级（CET6）报名条件

- 四级成绩 ≥ 425分

### 报名入口

- 官网报名：http://cet-bm.neea.cn/（公网）
- 教育网：http://cet-bm.neea.edu.cn/

### 报名流程

```
登录报名网站 → 注册账号 → 填写个人信息 → 选择考点（湖南农业大学） 
→ 选择考试类型（四级/六级） → 上传照片 → 确认报名 → 缴费
```

### 考试费用

| 考试类型 | 费用 |
|---------|------|
| 四级笔试（CET4） | 26元/人 |
| 六级笔试（CET6） | 28元/人 |
| 四级口试（CET-SET4） | 50元/人 |
| 六级口试（CET-SET6） | 50元/人 |

### 考试时间

| 考试类型 | 时间 |
|---------|------|
| 四级笔试 | 上午 9:00-11:20 |
| 六级笔试 | 下午 15:00-17:25 |
| 四级口试 | 5月或11月的一天 |
| 六级口试 | 四级口试次日 |

### 准考证打印

- 笔试准考证：考前一周内网上自行打印
- 口试准考证：考前一周内网上自行打印

### 成绩查询

- 成绩发布：考后约2个月
- 查询网站：中国教育考试网

### 注意事项

1. 四级与六级不可兼报
2. 缺考上一次考试者取消下一次报名资格
3. 学籍异动或照片问题无法网上报名的，联系教务处考试中心（0731-84617818）
4. 研究生相关问题联系研究生院培养科（0731-84618577）
5. 具体报名时间以教务处通知公告为准：https://jwc.hunau.edu.cn/tzgg/

### 成绩证明补办

如需补办CET或NCRE成绩证明，可参考教务处下载中心的《关于申请补办CET（笔试考试）成绩证明、全国计算机等级考试（NCRE）成绩证明流程及方法》。

## 二、全国计算机等级考试（NCRE）

### 考试时间

| 批次 | 考试时间 | 报名时间 |
|------|---------|---------|
| 上半年 | 3月 | 12月-1月 |
| 下半年 | 9月 | 6月-7月 |

### 考试科目

| 级别 | 常考科目 |
|------|---------|
| 一级 | 计算机基础及MS Office应用 |
| 二级 | MS Office高级应用、C语言、Python等 |
| 三级 | 网络技术、数据库技术等 |
| 四级 | 网络工程师、数据库工程师等 |

### 报名费用

- 一、二、三级：95元/科
- 四级：95元/科

### 报名入口

- 官网：https://ncre-bm.neea.cn/
- 选择考点：湖南农业大学（如设考点）

### 考试形式

- 全部上机考试
- 考试时间：一级90分钟，二、三、四级120分钟

### 成绩查询

- 考后约40天公布成绩
- 查询网站：中国教育考试网

## 五、考试备考建议

### 四六级备考

1. **词汇**：四级需掌握4500词汇，六级需掌握6000词汇
2. **听力**：每天坚持听力练习30分钟
3. **阅读**：提高阅读速度和准确率
4. **写作**：积累模板，多练习

### 计算机二级备考

1. 选择常用科目（如MS Office高级应用）
2. 刷真题，熟悉题型
3. 注重实操练习

## 六、常见问题

**Q：四六级必须考吗？**
A：四六级不是毕业硬性要求，但对就业、保研有帮助，建议参加。

**Q：四六级可以刷分吗？**
A：可以，每次考试都可以报名，成绩取最高分。

**Q：计算机二级考哪个科目好？**
A：非计算机专业建议考MS Office高级应用，实用性最强。

**Q：考试可以在校外考点报名吗？**
A：可以，但建议在校内考点报名，更方便。

**Q：错过报名时间怎么办？**
A：错过报名时间只能等下次，建议关注教务处通知，设提醒。
