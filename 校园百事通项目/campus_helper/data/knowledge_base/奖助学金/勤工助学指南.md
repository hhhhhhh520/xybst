# 湖南农业大学勤工助学指南

## 一、勤工助学概述

勤工助学是指学生在学校的组织下，利用课余时间，通过劳动取得合法报酬，用于改善学习和生活条件的社会实践活动。

### 申请资格

- 湖南农业大学全日制注册在校的家庭经济困难本专科学生

### 管理机构

- 学生资助管理中心负责岗位分配、考核监督及报酬发放
- 用人单位负责日常管理和考核

## 二、岗位类型

### 固定岗位

| 岗位类型 | 工作内容 |
|---------|---------|
| 学生助理 | 协助部门处理日常事务 |
| 博导助理 | 协助导师开展科研工作 |
| 科室助理 | 协助科室处理行政事务 |
| 图书馆助理 | 图书整理、借阅服务 |
| 实验室助理 | 协助实验室管理 |

### 临时岗位

- 短期项目工作
- 大型活动服务
- 临时性工作任务

## 三、薪资标准

| 岗位类型 | 薪资标准 |
|---------|---------|
| 固定岗位 | 400元以上/月 |
| 临时岗位 | 12元以上/小时 |

**注意**：具体薪资以当年度标准为准，报酬按月计算发放

## 四、申请流程

```
向学院学生工作组提交书面申请书
            ↓
学院审核，符合条件的填写申请表
            ↓
学院学工组汇总材料交学生资助管理中心
            ↓
学生资助管理中心审核、协调
            ↓
组织上岗人员培训
            ↓
签订上岗合同
            ↓
正式上岗
```

### 申请材料

1. 书面申请书
2. 《湖南农业大学学生校内勤工助学申请表》
3. 家庭经济困难学生认定证明
4. 农业银行卡号

## 五、岗位申请表填写说明

### 申请表内容

| 项目 | 说明 |
|------|------|
| 基本信息 | 姓名、性别、籍贯、民族、学院、年级、专业 |
| 联系方式 | 寝室号、联系电话、学号、身份证号 |
| 银行卡号 | 农业银行卡号（用于发放工资） |
| 申请原因 | 填写家庭基本收入情况及申请理由 |
| 岗位类型 | 固定岗位/临时岗位 |
| 家庭经济困难认定情况 | 特困/比较困难/一般困难/非困难 |

## 六、工作要求

### 学生权利

1. 有权了解用人单位的有关情况
2. 有权拒绝参加有害身体健康、危险的工作
3. 有权按一定标准取得劳动报酬

### 学生义务

1. 遵守用人单位规章制度
2. 认真完成工作任务
3. 接受用人单位考核
4. 不影响学业

### 考核要求

- 用人单位对在岗学生进行考核
- 考核结果影响工资发放
- 考核不合格可能被取消岗位

## 七、注意事项

1. 每学年申请一次
2. 一个学生只能从事一个勤工助学岗位
3. 填写资料必须真实，发现虚假材料取消录用资格
4. 上岗后遵守学校相关规定和国家法规
5. 工资发放问题可到学生资助管理中心查询

## 八、常见问题

**Q：勤工助学影响学习吗？**
A：勤工助学利用课余时间进行，学校会控制工作时长，一般不影响学习。

**Q：非困难学生可以申请吗？**
A：原则上仅限家庭经济困难学生申请，非困难学生一般不符合条件。

**Q：可以同时做多个岗位吗？**
A：不可以，一个学生只能从事一个勤工助学岗位。

**Q：工资什么时候发放？**
A：工资按月计算，一般次月发放到农业银行卡。

**Q：工作表现不好会怎样？**
A：考核不合格可能被取消岗位，影响后续申请。
