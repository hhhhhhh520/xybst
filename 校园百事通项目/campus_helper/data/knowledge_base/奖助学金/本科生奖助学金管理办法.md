# 湖南农业大学全日制本专科生奖助学金管理办法

> 依据《湖南农业大学全日制本专科生奖助学金管理办法》整理

## 第一章 总则

### 目的与意义

为激励学生勤奋学习、努力进取，在德、智、体、美等方面全面发展，帮助家庭经济困难学生顺利完成学业，根据国家有关规定，结合学校实际，制定本办法。

### 适用范围

本办法适用于学校全日制普通本专科学生（含第二学士学位学生）。

## 第二章 奖学金类别

### 一、国家奖学金

**奖励对象：** 特别优秀的全日制本专科学生

**奖励标准：** 每生每年8000元

**申请条件：**

1. 具有中华人民共和国国籍
2. 热爱社会主义祖国，拥护中国共产党的领导
3. 遵守宪法和法律，遵守学校规章制度
4. 诚实守信，道德品质优良
5. 学习成绩优异，社会实践、创新能力、综合素质等方面特别突出
6. 评审学年学习成绩排名与综合考评成绩排名均位于前10%（且没有不及格科目）

### 二、国家励志奖学金

**奖励对象：** 品学兼优的家庭经济困难学生

**奖励标准：** 每生每年5000元

**申请条件：**

1. 符合国家奖学金申请条件第1-4项
2. 家庭经济困难，生活俭朴
3. 学习成绩优异，学习成绩排名与综合考评成绩排名有一项位于前10%，另一项位于前30%
4. 没有不及格科目

### 三、国家助学金

**资助对象：** 家庭经济困难学生

**资助标准：**

| 等级 | 金额 | 资助对象 |
|------|------|----------|
| 一等 | 4400元/年 | 特别困难学生 |
| 二等 | 3300元/年 | 困难学生 |
| 三等 | 2200元/年 | 一般困难学生 |

### 四、优秀学生奖学金

**奖励标准：**

| 等级 | 金额 | 比例 |
|------|------|------|
| 特等奖 | 3000元/年 | 按学院学生数的1%评定 |
| 一等奖 | 1500元/年 | 按班级学生数的3%评定 |
| 二等奖 | 1000元/年 | 按班级学生数的8%评定 |
| 三等奖 | 500元/年 | 按班级学生数的15%评定 |

**申请条件：**

1. 热爱祖国，拥护中国共产党的领导
2. 遵守法律法规和学校规章制度
3. 诚实守信，道德品质优良
4. 学习成绩优良，参评学年无不及格科目
5. 综合考评成绩位于班级前列

### 五、单项奖

**奖励对象：** 在文艺表演、体育竞赛、学科竞赛及科技创新等方面表现突出的优秀学生个人

**奖励标准：** 每人每项不超过500元

**评定条件：**

1. 文艺表演：参加省级以上比赛获奖
2. 体育竞赛：参加省级以上比赛获奖
3. 学科竞赛：参加省级以上比赛获奖
4. 科技创新：获得专利、发表学术论文或参加省级以上创新创业竞赛获奖

## 第三章 奖助学金评审

### 评审时间

- **国家奖学金、国家励志奖学金**：每年9-10月评审
- **国家助学金**：每年9-11月评审
- **优秀学生奖学金**：每年10月左右评审上一学年度奖学金

### 评审程序

1. **学生申请**：学生向所在学院提出申请，提交相关材料
2. **班级评议**：班级奖助学金评审小组进行民主评议
3. **学院初审**：学院奖助学金评审委员会进行评审，确定推荐名单
4. **学校审定**：学校奖助学金评审领导小组审定最终名单
5. **公示**：评审结果在校内公示5个工作日
6. **表彰发放**：公示无异议后，发文表彰并发放奖助学金

### 评审原则

1. **公平、公正、公开**：严格按条件和程序评审
2. **择优评定**：符合条件的学生中择优推荐
3. **倾斜政策**：同等条件下，优先考虑建档立卡家庭学生、农村低保家庭学生、农村特困救助供养学生、孤残学生、烈士子女等

## 第四章 家庭经济困难学生认定

### 认定等级

| 等级 | 说明 |
|------|------|
| 特别困难 | 学生家庭经济特别困难，难以维持基本学习生活费用 |
| 困难 | 学生家庭经济困难，学习生活费用存在较大缺口 |
| 一般困难 | 学生家庭经济有一定困难，学习生活费用存在缺口 |

### 认定程序

1. 学生本人申请
2. 班级民主评议
3. 学院审核认定
4. 学校学生资助管理中心复核
5. 建立家庭经济困难学生档案

### 需提交材料

1. 《家庭经济困难学生认定申请表》
2. 家庭所在地乡镇（街道）以上民政部门出具的家庭经济困难证明
3. 其他证明材料（如低保证、残疾证、重大疾病诊断证明等）

## 第五章 勤工助学

### 岗位设置

| 岗位类型 | 说明 | 报酬标准 |
|----------|------|----------|
| 固定岗位 | 持续一个学期以上的长期岗位 | 按月计酬，原则上不低于当地最低工资标准 |
| 临时岗位 | 不满一个学期的短期岗位 | 按小时计酬，原则上不低于12元/小时 |

### 申请条件

1. 家庭经济困难学生
2. 学有余力，不影响正常学习
3. 遵守学校规章制度
4. 身体健康，能够胜任工作

### 申请程序

1. 学生向所在学院或用工部门提出申请
2. 学生资助管理中心审核
3. 安排岗位并签订协议
4. 学生上岗工作
