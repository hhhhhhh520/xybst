# 湖南农业大学学生常见问题FAQ

> 整理自学生高频咨询问题

## 学籍与注册

### Q1: 新生入学需要准备什么？

**证件材料**：
- 录取通知书
- 身份证原件及复印件
- 高考准考证
- 党团组织关系转接材料
- 一寸、二寸照片若干
- 户口迁移证（如需迁户口）

**生活用品**：
- 床上用品（可校内购买或自备）
- 洗漱用品
- 换洗衣物
- 学习用品

### Q2: 学生证丢了怎么补办？

1. 到保卫处挂失
2. 携带身份证到学生工作处申请补办
3. 缴纳工本费
4. 等待领取新证

### Q3: 学籍证明在哪里开？

- 登录校园信息门户自助打印
- 或到教务处学籍科办理

## 请假与考勤

### Q4: 请假怎么办理？

**请假流程**：
1. 填写请假申请表（教务处下载中心下载）
2. 病假需附校医院证明
3. 3天以内：辅导员审批
4. 3天以上一周以内：学院审批
5. 一周以上：教务处审批

### Q5: 旷课有什么后果？

| 旷课时数 | 处分等级 |
|----------|----------|
| 10-19学时 | 警告 |
| 20-29学时 | 严重警告 |
| 30-39学时 | 记过 |
| 40-49学时 | 留校察看 |
| 50学时以上 | 开除学籍 |

### Q6: 累计请假超过学期总学时三分之一怎么办？

应当办理休学手续，否则可能被退学。

## 选课与考试

### Q7: 忘记选课了怎么办？

- 开学第1-2周可以补退选
- 但热门课程可能已满
- 建议提前设置选课提醒

### Q8: 选课系统进不去怎么办？

1. 错峰选课（早晚时段）
2. 使用校园网访问
3. 更换浏览器（推荐谷歌浏览器）
4. 清除浏览器缓存

### Q9: 考试缓考怎么申请？

1. 考试前提交缓考申请
2. 附相关证明（如病历）
3. 教务处审批
4. 参加下学期初的补考

### Q10: 考试挂科了怎么办？

- 参加下学期初的补考
- 补考不及格需重修
- 重修需缴纳重修费

## 成绩与学分

### Q11: 成绩查询在哪里？

登录校园信息门户 → 教务管理 → 学生服务 → 成绩查询

### Q12: 绩点怎么计算？

绩点 = Σ（课程绩点 × 课程学分）/ Σ课程学分

| 百分制成绩 | 绩点 |
|------------|------|
| 90-100 | 4.0 |
| 85-89 | 3.7 |
| 82-84 | 3.3 |
| 78-81 | 3.0 |
| 75-77 | 2.7 |
| 72-74 | 2.3 |
| 68-71 | 2.0 |
| 64-67 | 1.5 |
| 60-63 | 1.0 |
| 60以下 | 0 |

### Q13: 毕业需要多少学分？

- 四年制本科：150-170学分
- 五年制本科：180-200学分
- 具体以专业培养方案为准

### Q14: 学分不够怎么办？

- 每学期检查学分完成情况
- 不够的学分需在后续学期补修
- 延期毕业需申请，最长延期2年

## 奖学金与资助

### Q15: 奖学金什么时候评定？

- 国家奖学金、励志奖学金：每年9-10月
- 优秀学生奖学金：每年10月
- 关注班级群通知

### Q16: 申请奖学金需要什么条件？

主要条件：
- 成绩排名位于班级前列
- 无不及格科目
- 无违纪处分
- 具体条件因奖项而异

### Q17: 家庭经济困难学生怎么申请资助？

1. 开学初填写《家庭经济困难学生认定申请表》
2. 提交家庭经济困难证明
3. 班级民主评议
4. 学院审核认定
5. 可申请助学金、勤工助学等

## 转专业与辅修

### Q18: 转专业什么时候可以申请？

一般在大一结束或大二结束，具体时间以教务处通知为准。

### Q19: 转专业需要什么条件？

- 学习成绩优良
- 确有专长或特殊原因
- 接收学院考核通过
- 具体以当年转专业文件为准

### Q20: 可以辅修第二专业吗？

可以。一般在二年级开始辅修，需满足：
- 主修专业成绩良好
- 有足够学习时间
- 按规定缴纳辅修费用

## 宿舍与生活

### Q21: 宿舍可以自己选吗？

一般由学校统一安排，按专业班级分配。特殊情况可申请调整。

### Q22: 宿舍可以用电器吗？

允许使用小功率电器（如台灯、风扇），禁止使用：
- 电饭锅
- 电热毯
- 热水器
- 大功率电器（≥500W）

### Q23: 宿舍网络怎么办理？

1. 登录信息中心网站申请
2. 缴纳网络费
3. 设置账号密码
4. 连接校园网

### Q24: 食堂饭卡（校园卡）丢了怎么办？

1. 立即挂失（校园信息门户或电话）
2. 携带身份证到校园卡服务中心补办
3. 缴纳工本费

## 图书馆

### Q25: 图书馆开放时间？

- 借阅区：8:00-22:00
- 自习室：7:00-23:00
- 节假日另行通知

### Q26: 借书可以借几本？借多久？

- 本科生：10册，30天
- 可续借1次，续期30天
- 逾期需缴纳滞纳金

### Q27: 自习室怎么占座？

- 通过图书馆微信公众号预约
- 预约后30分钟内签到
- 逾期不签到将被记录

## 毕业与就业

### Q28: 毕业论文什么时候开始准备？

一般在大四上学期开始选题，大四下学期完成写作和答辩。

### Q29: 三方协议有什么用？

三方协议是毕业生、用人单位、学校三方签订的就业协议，用于：
- 确认就业意向
- 办理报到证
- 转递档案户口

### Q30: 档案会寄到哪里？

| 就业情况 | 档案去向 |
|----------|----------|
| 签就业协议 | 用人单位或人才市场 |
| 升学 | 录取学校 |
| 未就业 | 生源地人才市场 |
