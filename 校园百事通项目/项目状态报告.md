## 四、各模块详情

### 4.1 后端服务

**启动方式:**
```bash
cd campus_helper
venv\Scripts\activate
python backend/main.py
```

**API端点:**
- `GET /` - 健康检查
- `POST /api/chat` - 对话接口
- `GET /api/knowledge/search` - 知识库搜索
- `GET /docs` - API文档

**核心服务:**
| 服务 | 文件 | 功能 |
|------|------|------|
| RAG检索 | `rag_retriever.py` | 向量+关键词混合检索 |
| Agent工作流 | `agent_workflow.py` | 意图识别、槽位填充 |
| LLM服务 | `llm_service.py` | 调用大语言模型 |
| 知识库 | `knowledge_base.py` | 文档管理 |

### 4.2 前端界面

- 单HTML文件，内联CSS/JS
- 响应式设计，支持移动端
- 功能：聊天界面、快速回复、服务状态检测

### 4.3 知识库

**当前状态:**
- 12个分类目录已创建
- 仅3个示例文档:

  - `tsg_policy_图书馆开放时间.md`
  - `xgc_policy_奖学金评定办法.md`

**待补充内容:**
